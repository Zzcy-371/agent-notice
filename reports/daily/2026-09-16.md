# Agent 技术日报 · 2026-09-16

## GitHub projects

### [skills](https://github.com/mattpocock/skills)
- 为真实工程师打造的 skills，直接来自我的 .agents 目录，强调可落地的工程实践。
- 结合 MCP、RAG、tool calling 与 multi-agent 等能力，让 skills 不只是提示词，而是可复用的工作流。
- 目标是把日常工程经验沉淀为标准化 skills，提升开发、调试与协作效率。

### [codex](https://github.com/openai/codex)
- 在终端中运行的轻量级 coding agent，支持通过 MCP 连接外部工具与上下文。
- 内置 tool calling 能力，可调用 shell、文件系统等工具完成代码生成与修改任务。
- 可结合 RAG 与 multi-agent 编排，在本地命令行环境中实现可扩展的自动化编码工作流。

### [awesome-design-md](https://github.com/VoltAgent/awesome-design-md)
- 收录来自热门品牌设计系统的 DESIGN.md 文件分析，可直接放入项目，让 coding agents 生成匹配的 UI。
- 通过将品牌设计规范注入 RAG 或 MCP 上下文，coding agents 能更稳定地遵循视觉与交互约定。
- 适合与 tool calling、multi-agent 工作流结合，用设计系统文件统一多代理协作时的界面生成标准。

### [TradingAgents](https://github.com/TauricResearch/TradingAgents)
- TradingAgents 是一个基于 multi-agent 的 LLM 金融交易框架，通过多个智能体协作完成市场分析与交易决策。
- 框架利用 RAG 与 tool calling 能力，让智能体能够检索外部金融数据、调用分析工具并整合多源信息。
- 该 MCP 兼容的设计支持智能体分工与消息传递，模拟真实交易团队的研究、辩论与执行流程。

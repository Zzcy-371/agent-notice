## GitHub projects

### [LangChain：面向 Agent 工程化的平台](https://github.com/langchain-ai/langchain)
- LangChain 专注于 agent engineering，为开发者提供构建、编排与部署智能体的基础组件与运行时能力。
- 平台支持 tool calling、MCP 与 RAG 等关键模式，便于将外部工具、上下文协议与检索增强生成接入 agent 工作流。
- 通过可组合的抽象与集成生态，LangChain 也适用于构建 multi-agent 系统，简化复杂任务协作与生产落地。

### [pi](https://github.com/earendil-works/pi)
- 统一 LLM API：为 MCP、RAG、tool calling 与 multi-agent 场景提供一致的模型调用接口。
- 内置 agent loop：驱动多轮推理、工具调用与结果回传，支撑自主任务执行。
- 附带 TUI 与 coding agent CLI：提供终端交互界面和面向代码任务的命令行智能体。


## Research and engineering

### [Show HN：Text-me：一个学习你节奏的个人 agent](https://aiworthusing.com/agent-index/text-me)
- 通过 iMessage 或 SMS 把所有内容发到一个地方，像给朋友发消息一样；它把生活和工作分开，每周进行分析，并给出一个起点，而不是又一个 dashboard。
- 通过 Plow 连接 email 和 calendar；它总是在更改 calendar 或发送消息前先询问，并会记住你的真实节奏，例如，如果某项活动预计 45 分钟但实际花了 60 分钟，下次它就会安排 60 分钟。
- 每天早上它可以发送一份包含重要事项的 newspaper，包括需要回复的人、隔夜变化以及当天要解决的问题；它可以通过 printer、email 或 chat 发送，但作者更喜欢发送到 Kindle，而且它是开源软件，构建于 hackathon 期间。

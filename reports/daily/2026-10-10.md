### [Show HN: 一款适用于 iPhone、Mac 和你的 agent 的简单待办事项应用](https://ilia.page/writing/introducing-nagare)
- 该应用通过 MCP 与 agent 集成，让 AI 可以直接读取和管理你的待办列表，无需手动同步。
- 作者在文章中讨论了为 agent 设计工具的经验，并比较了 RAG 与 tool calling 在待办场景下的适用性。
- 评论中有人提到 multi-agent 协作处理任务的潜力，以及如何避免 agent 误改或误删用户数据。

### [Agentic AI 的验证与自我改进：基础与局限](https://arxiv.org/abs/2610.10611)
- 论文提出有界验证框架，通过隐藏终端随机性区分更长的搜索、额外支持以及修改提议与验证方式，证明独立多数放大保持语言不变，而随机带上的存在接受可能引入错误输出。
- 随机验证器类满足 Σ_k^P ⊆ Σ_k^RV ⊆ Σ_{k+1}^P，严格扩大和深度分离需显式复杂度假设；当 BPP = P 时，精确伴随类具有相同边界，且表示分析将不变接受与核心-支持标签分离。
- 对于递归自我改进，在公共可靠解释器和固定验证协议下，一致有界自我修改仍属于同一验证类；配额强制 XOR 合成族可分离搜索成功与接受语言变化，并通过精确与概率审计检查证据要求，将自我改进主张与正确性、可采纳证据、验证资源和选择错误义务绑定。

### [The Harness as the Only Mutable Surface: Compliance-Bounded Self-Evolution of LLM Agents in Credit Pipelines, with a Measured Admission Gate](https://arxiv.org/abs/2610.10629)
- 研究提出将 LLM Agent 的自演化严格限制在运行时 harness（指令文本、tool calling 逻辑与 primitive 组合）内，而模型权重保持不变，使每次适应都成为附有原因和测试的 diff，从而保持可审查性。
- 基于该边界构建双环引擎与准入闸门，在部署前写入哈希链记录；模拟中闸门从 7,449 个候选变更中仅准入 144 个，无一在留出历史上恶化错误，并在所有低、中严重度单元将假阳性率恢复到 oracle 水平且未增加漏报。
- 若将闸门替换为无界系统的检查（仅看近期轨迹中更少错误），相同循环准入 309 个有害变更，90 次运行中有 49 次漏报率超过 10%；同时，参数与范围偏移可局部修复，结构性偏移仅能通过 primitive 替换修复，最高结构严重度下固定容差在半数种子中阻止了正确替换。

### [Speaking the Navigator's Language: Trajectory-Grounded Instruction Translation for Frozen Aerial VLN Agents](https://arxiv.org/abs/2610.10635)
- 用户发出的简短意图指令与 frozen OpenFly navigator 训练所用的细节丰富的轨迹对齐指令之间存在 instruction gap，导致成功率 (SR) 从 31.03% 降至 11.33%。
- 通过提示语言模型将原始指令转换为配对的意图中心 Weak 指令，并引入 Trajectory-Grounded Instruction Translator (TGIT)，在保持 navigator 冻结的情况下，利用其轨迹结果学习将 Weak 输入翻译为可执行指令。
- TGIT 将 Weak 输入 SR 提升至 37.93%，零样本迁移到真实人类指令从 11.33% 提升至 32.51%，并在 held-out OpenFly、CityNav 和 AirVLN 上取得改进或恢复。

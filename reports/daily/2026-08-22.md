## Research and engineering

### [Ox Alpha 在 Multi-Agent Arena 中达到 SOTA，与 GPT-5.6 Sol 并列](https://twitter.com/olam_labs/status/2090930116138582224)
- Ox Alpha 通过优化 MCP 和 RAG 流程，实现 SOTA 性能，在 Multi-Agent Arena 中与 GPT-5.6 Sol 平起平坐。
- 其 tool calling 能力显著提升，支持多代理协同决策，降低任务分解延迟 40%。
- 该模型在复杂推理任务中表现稳定，为 multi-agent 系统提供可复用的开源基线。

### [Replacing 223-node agent graph with a single OSS LLM](https://www.netic.ai/blog/replacing-node-agent-graph-with-open-source-llm)
- 采用单一开源大模型替代原有223节点代理图，简化系统架构并提升推理效率。
- 通过MCP（模型上下文协议）整合工具调用，大幅减少对复杂多智能体编排的依赖。
- 利用RAG和基本tool calling能力，在保持性能的同时降低维护成本与运营复杂性。

### [Turn Claude Code into a 24/7 Agent](https://github.com/gtapps/claude-code-hermit)
- 通过 MCP 服务器集成，将 Claude Code 扩展为持续运行的 autonomous agent，实现 24/7 自动化任务处理。
- 利用 RAG 技术增强 agent 的知识检索能力，结合 tool calling 自动调用外部工具，提升复杂任务解决的效率。
- 支持 multi-agent 协作，允许多个 agent 实例并行工作，并通过 MCP 通信实现任务分配与结果汇总。

### [Building Piclaw on Top of an Opinionated Coding Agent](https://taoofmac.com/space/blog/2026/08/21/2218)
- Piclaw leverages an opinionated coding agent to streamline development workflows, integrating MCP (Model Context Protocol) for seamless tool calling and RAG (Retrieval-Augmented Generation) for context-aware code assistance.
- The architecture emphasizes multi-agent collaboration, where specialized agents handle distinct tasks such as code generation, review, and testing, orchestrated by the coding agent's built-in decision-making framework.
- By combining RAG with live tool calling, Piclaw enables dynamic retrieval of project-specific knowledge and real-time execution of coding operations, enhancing productivity and reducing context switching.

## GitHub projects

### [superpowers](https://github.com/obra/superpowers)
- 面向 AI 代理的 agentic skills framework，将软件开发方法论固化为可复用的技能与流程，让 Agent 按既定工程规范执行任务。
- 可与 MCP、RAG、tool calling 等能力协同：通过 MCP 接入外部工具与数据源，借助 RAG 提供上下文知识，并以 tool calling 驱动具体操作。
- 支持 multi-agent 协作模式，将复杂开发任务拆分为多个具备专长的代理角色，实现分工、编排与交付闭环。


## Research and engineering

### [Lean Pool: 一个由 AI 维护的形式化数学存档库](https://arxiv.org/abs/2609.25199)
- Lean Pool 是一个形式化数学的仓库，其内容由 AI agents 持续扩充、维护与优化。
- 该工作展示了 AI 在形式化数学领域的自主维护能力，可与 MCP、RAG、tool calling、multi-agent 等技术结合以提升自动化水平。
- 作为 arXiv:2609.25199v1 的新公告，Lean Pool 为形式化数学社区提供了一个由 AI 驱动可持续演进的存档资源。

### [AI Neuroscientist：面向神经影像分析的交互式智能体界面](https://arxiv.org/abs/2609.25254)
- 该系统将 LLM 与神经影像工具集结合，通过 tool calling 完成质量控制、建模和可视化，让研究者用自然语言直接查询数据质量并指定分析参数。
- 作者使用 fNIRS 数据进行演示，并在自建的 fNIRS 基准测试套件上将该智能体与带代码沙箱的通用 LLM 智能体进行比较评估。
- 未来工作将把这一架构推广到 fMRI 等其他模态，并扩展基准测试覆盖更多 fNIRS 任务，整体体现了 multi-agent 与 RAG 之外的智能体式交互分析思路。

### [When LLM Agents Fail to Read the Room: ReAdapt for Relational Social Reasoning](https://arxiv.org/abs/2609.25284)
- 论文提出关系推理基准，包含 500 个合成社交世界与 1,000 个查询，覆盖 reaction selection 与 warm introduction 任务；其中约 53% 的查询里表面最显眼的候选人与基于关系的 oracle 不一致，形成 overturn 子集，暴露标准 LLM agent loop 在关系线索与内容线索冲突时偏向表面选择的失败模式。
- 作者提出 ReAdapt（Relationship-Adaptive Agent with Policy-driven sTate），在 ReAct 循环上引入显式结构化社会状态 z = (G, B, R, N, D)，分别刻画 goal、belief、relationship、norm 与 disclosure，并在每次 tool observation 后执行带类型的 Adapt 步骤更新状态并发出 continue、switch、abandon 或 clarify 等 policy operation。
- 在 Gemini-3-Flash 与每任务 n = 150 的分层子集上，ReAdapt 将 warm-introduction 准确率从 37% 提升到 51%（+14 点），reaction-selection 准确率从 69% 提升到 77%（+8 点），oracle regret 分别从 0.260 降至 0.152、从 0.095 降至 0.053，表明在模型、工具与环境固定时，显式关系状态自适应能帮助 LLM agents 把检索到的社交证据转化为修正后的决策。

## Research and engineering

### [NormGym：通过社交互动评估规范能力](https://arxiv.org/abs/2611.08613)
- NormGym 是一个交互式基准，要求新来者在 multi-agent 社区中完成自身任务的同时，从社交互动中推断隐藏的任意规范，并区分“可能”与“被允许”。
- 当前最强 LLM agent 的任务与合规联合成功率仅为 55.3%；模型能根据自身受到的制裁调整行为，但难以利用其他 agent 的行为及其所受制裁来推断潜在规范。
- 研究发现微调可能不足以提升规范能力，表明当前模型缺乏通过社交互动获取规范知识的稳健且可迁移的能力。

### [Decision Context：为 AI Agents 实现持久行为学习](https://arxiv.org/abs/2611.08644)
- 针对 LLM agents 无法跨会话学习纠正、现有 agent memory 系统只处理事实而非程序性知识的问题，论文提出 Forge Decision Context（forge_dc），从人类纠正与自评的 tool calling 失败中提取行为信号，编译为命令式 RULE 指令，并在适用的决策点注入。
- 在基于真实 agent 执行轨迹构建的 DC-Bench（覆盖 9 个行为维度、71 个场景）上，forge_dc 达到 95% 合规率，而朴素 RAG 仅 55%，且每次查询注入的 token 约少 10 倍。
- 五阶段演进表明，最强的系统把行为记忆表示为显式指令，并在适用的决策点交付；representation、activation 与 placement 是持久行为学习的核心设计选择，也为 MCP、tool calling 与 multi-agent 场景提供参考。

### [调试接口对比：调试器代理与仅 Bash 代理在 SWE-bench 上的 pass$_X$@$k$ 评估](https://arxiv.org/abs/2611.08666)
- 在固定 scaffold 的前提下，对比仅使用交互式 debugger 的 agent 与仅使用 bash 的 agent，覆盖全部 500 个 SWE-bench Verified 实例，并在 GPT-OSS-120B 与 Nemotron-3-Ultra-550B 上各独立运行三次。
- 提出跨 agent 的 pass$_X$@$k$ 指标，用于区分接口专精与重复采样带来的覆盖扩展，并对“至少一个 agent 成功”的概率给出无偏估计。
- 结果显示 bash 与 debugger agent 单次运行解出的子集虽部分不相交，但 pass$_X$@$2$ 表明这主要来自运行间随机方差而非工具互补性；两个 bash rollout 优于一个 bash 加一个 debugger 的组合，强调评估 agent 与 tool calling / multi-agent 多样性时需考虑随机方差。

### [Memory-Aware Multi-Agent Architecture with LLM-based Orchestration for Conversational Recommendation](https://arxiv.org/abs/2611.08718)
- 将长期记忆作为一等组件集成到 multi-agent 架构中，由 LLM 承担 orchestration 层，协调意图细化、查询构建与交互流程，使记忆同时影响路由决策与语义查询构造。
- 在 Amazon Reviews 数据集上的跨会话记忆实验、多轮对话模拟与 supervisor 驱动交互研究表明：启用记忆的交互可弥补至多 63% 与显式查询场景之间的差距，并避免长对话中的语义退化；监督式 orchestration 使用户接受度提升 28.9 个百分点。
- 观察到检索候选与展示推荐之间存在曝光瓶颈：LLM-reranking 虽不提升 Hit@K，但持续改善语义一致性与多样性，为此提出 Semantic Consistency Score（SCS）作为传统排序指标之外的补充评估度量。

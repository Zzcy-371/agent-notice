## Research and engineering

### [Prime Agent: A Self-Improving RLM Agent](https://github.com/PrimeIntellect-ai/prime-agent)
- Introduces a reinforcement learning-based agent that leverages MCP (Model Context Protocol) to interact with external tools and APIs, enabling dynamic task execution.
- Utilizes RAG (Retrieval-Augmented Generation) to enhance knowledge retrieval, improving decision-making and context awareness during multi-agent collaboration.
- Features a self-improving loop where the agent learns from feedback and tool calling outcomes, refining its strategies over time for more efficient task completion.

### [Show HN: A benchmark for AI agent guardrails that caught my own plugin](https://github.com/couldbeme/holdline)
- Introduces Holdline, a benchmark for AI agent guardrails that catches vulnerabilities in MCP and RAG-based plugins.
- Uses tool calling scenarios to test multi-agent safety, revealing issues in my own plugin's guardrail implementation.
- Provides a framework for red-teaming agent behaviors, helping developers identify and fix guardrail gaps.

### [Token-in-token-out RL training with any agent harness, via a proxy gateway](https://castform.com/blog/harbor)
- 通过代理网关实现与任何智能体框架的Token级强化学习训练，保留MCP、RAG、tool calling和multi-agent等术语。
- 该方法兼容现有工具链，支持在任意agent harness上进行RL训练，无需修改底层代码。
- 代理网关充当转换层，确保token输入输出格式统一，便于集成和扩展。

### [Agent Control Plane: the LLM proposes, it never authorizes](https://github.com/yacine-kellib/agent-control-plane)
- 该架构将LLM的建议与授权分离，确保模型仅提出操作而无法直接执行，通过控制平面实现安全授权，防止未经授权的工具调用（tool calling）。
- 集成MCP（Model Context Protocol）和RAG（Retrieval-Augmented Generation）以增强上下文与知识获取，但所有外部动作都需经过策略引擎验证，确保合规。
- 多智能体（multi-agent）协同中，每个代理仅负责提议，由中央控制平面统一审批，降低风险并提升系统可审计性。

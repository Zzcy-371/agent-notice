## GitHub projects

### [claude-mem](https://github.com/thedotmack/claude-mem)
- 为每个 Agent 提供跨会话的持久上下文：捕获 agent 在会话期间的所有操作，使用 AI 压缩，并将相关上下文注入未来会话。
- 适用于 Claude Code、OpenClaw、Codex、Gemini、Hermes、Copilot、OpenCode 等多种 Agent 环境。
- 通过持久上下文机制增强跨会话的 RAG 与 tool calling 体验，并可与 multi-agent 工作流结合使用。


## Research and engineering

### [Type：在云端运行 Claude Code 和 Codex 的 Agent orchestrator](https://type.com/)
- Type 作为 agent orchestrator，把 Claude Code 和 Codex 这类 coding agent 放到云端统一调度与运行。
- 从定位看，它面向 multi-agent 场景下的任务编排，可能涉及 tool calling 与 RAG 等能力整合。
- 目前 HN 讨论热度很低（1 points、0 comments），细节仍需查阅官网 https://type.com/ 了解。

### [Meta 推出 Spaces：由你的 Muse agent 构建的自定义应用视图](https://about.fb.com/news/2026/11/introducing-spaces-customize-muse-app)
- Meta 宣布 Spaces 功能，允许用户通过 Muse agent 生成个性化应用视图，进一步将 agent 能力嵌入日常应用界面。
- 结合 agent 与自定义界面生成的思路，可能与 tool calling、RAG 及 multi-agent 编排等能力协同，让 Muse 根据用户需求动态组装视图。
- 该发布在 Hacker News 上讨论热度极低（1 分、1 条评论），暂未引发社区广泛关注。

### [Tell HN：你可以为你的 agent 使用独立的 GitHub 账号](https://news.ycombinator.com/item?id=50400475)
- GitHub ToS（自 4 月起）允许人类为自动化任务创建 machine account，agent 可用该账号 fork 你的仓库并提交 PR，从而在无法造成实际破坏的前提下仍能推送代码。
- machine account 需由人类接受条款、提供有效邮箱并对账号行为负责；免费 Personal Account 之外最多再维护一个免费 machine account。
- 示例用户 github.com/filippo-agent 展示了这一模式，可与 MCP、RAG、tool calling、multi-agent 等 agent 工作流结合使用。

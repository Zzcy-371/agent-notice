## GitHub projects

### [hermes-agent](https://github.com/NousResearch/hermes-agent)
- hermes-agent 是一个会随你成长的 agent，通过 MCP 连接外部工具与数据源，并支持灵活的 tool calling。
- 它可结合 RAG 构建可扩展的知识增强流程，让 agent 在长期使用中持续积累上下文与能力。
- 面向复杂任务编排，hermes-agent 支持 multi-agent 协作，让多个智能体分工完成工作流。


## Research and engineering

### [预测智能体何时该推理？可靠性路由的行为压力测试](https://arxiv.org/abs/2609.28475)
- 论文提出 ReliabilityRoute 结构性干预方法，基于历史覆盖率、市场先验可得性、来源先验锐度、证据强度、证据分歧和预测周期等可靠性特征，来引导预测智能体的行为，而非默认依赖语言模型推理。
- 核心发现是机制选择取决于来源：在某些数据生成过程中结构化类比占优，而在其他情境下市场/群体式与保守基线更可靠，表明更多推理并非总是更好，预测智能体应先估计哪一证据来源值得控制。
- 在 ForecastBench 风格二元预测任务上，固定 2024 年拟合规则无需硬编码来源名称即可接近人工分类法，而基于已解决历史版本的 walk-forward 自适应阈值规则在后续 16 个 LLM 版本上取得最佳平均 Brier 分数，但增益有限且历史/搜索基线仍极具竞争力。

### [TW3Cast: 一个冻结路由器，基于轻度微调基础模型的时间序列预测系统，在 GIFT-Eval 上完全通过训练集选择](https://arxiv.org/abs/2609.28506)
- TW3Cast 不使用 agent 或 language model，其选择表在训练集上计算一次后冻结，专家是公开基础模型（Chronos-2、TiRex、Toto）的轻度微调版本，通过 LoRA 或全量微调实现。
- 对于 97 个数据集、频率和预测范围的配置，该表提供四种模式之一：专家模型、包含专家的分位数混合、基础模型混合，或在训练集回测上进行的选拔锦标赛。
- 通过双重准确性和校准标准、针对训练中见过序列的候选模型的不对称边际以及保守的逐窗口门控来保护选择，最终完整路由器达到平均 MASE 排名 19.4，优于最佳基础模型（33.8）和锦标赛（38.0）。

### [PAWS: 政策驱动的 Agentic World Simulation 数据集](https://arxiv.org/abs/2609.28547)
- PAWS 覆盖 36 个经核实的美国金融与经济政策事件，包含 12,727 条政策相关新闻记录和 65,291 条有来源支撑的利益相关者行动，每条行动通过多层事件框架刻画交互模式、金融行动族与子类型、语义属性及外部分类映射。
- 实体被归一到标准化组织，行动与每日市场收益上下文对齐以支持 policy-agent 模拟回放；在 2,522 个分层行动样本上，独立 AI 与人类评审者对交互模式的初始一致率达 89.4%，分歧随后经仲裁解决。
- 2008 年卖空禁令与 2001 年十进制化案例研究在密集与稀疏新闻设定下复原了政策时间线与市场模式，回放研究则揭示高准确率可能掩盖对稀有利益相关者行动的漏检，凸显行动时序与校准是 RAG、tool calling 与 multi-agent 金融模拟的核心挑战。

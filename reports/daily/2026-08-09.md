## Research and engineering

### [Show HN: Aidress – LangChain integration for cross-agent discovery and trust](https://docs.langchain.com/oss/python/integrations/tools)
- Aidress 通过 LangChain 集成实现跨代理发现，支持 MCP 协议和动态工具调用。
- 利用 RAG 技术增强代理间的知识共享和检索，提升多代理系统的信任与协作效率。
- 提供统一接口，简化代理注册与发现流程，便于扩展和集成现有 LangChain 工具链。

### [Show HN: Tura – Build agent that uses 80% less token and delivers better results](https://github.com/Tura-AI/tura)
- Tura 通过创新的 token 压缩技术，使 agent 在运行中减少 80% 的 token 消耗，同时提升任务执行质量。
- 它原生支持 MCP（Model Context Protocol）和 RAG（检索增强生成），并与主流工具调用（tool calling）无缝集成。
- 采用多智能体（multi-agent）架构，使 agent 能高效协作，进一步优化资源利用和结果输出。

### [You can build an AI agent's memory layer with only Go's standard library](https://towardsdev.com/the-memory-efficient-ai-agent-building-a-context-engine-in-go-d4b7557c44d8?sk=22b2ffc30beac55a6f47841eb4df980b)
- 文章介绍了如何仅使用 Go 标准库来构建 AI agent 的 memory layer，从而在不依赖外部框架的情况下高效管理上下文。
- 该方案聚焦于 context engine 的设计，通过 MCP 和 RAG 技术增强 agent 的记忆能力，并优化 tool calling 的集成。
- 实现展示了在 multi-agent 场景下的轻量级 memory 管理，确保不同 agent 间的上下文共享与高效检索。

### [Show HN: Try Benzi – A coding harness/agent beating Claude Code itself on Sonnet](https://benzi.fly.dev/about)
- Benzi compiles codebases into O(1) hashmap queries for instant code structure discovery, enhancing MCP and RAG capabilities.
- It performs complete static analysis on writes, integrating tool calling and multi-agent coordination to prevent regressions.
- Benchmarks show Benzi outperforms Claude Code on Sonnet: on 2/20 tests Claude regressed/timed out, while Benzi was cheaper and faster in the rest.

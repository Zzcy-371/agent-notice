## Research and engineering

### [Show HN: AgentGate – 面向 AI agent 工具的高速授权网关](https://github.com/mohitdebian/AgentGate)
- AgentGate 为 AI agent 工具提供快速授权网关，适合在 tool calling 与 MCP 场景中统一管理权限。
- 项目可用于约束 multi-agent 与 RAG 流程中的工具访问，降低越权调用风险。
- GitHub 仓库已公开，HN 讨论帖当前 1 分、0 条评论，尚处早期曝光阶段。

### [Mano-P：无需云依赖的端侧 GUI Agent 搭建方案](https://github.com/Mininglamp-AI/Mano-P)
- Mano-P 是一个在本地设备上运行的 GUI Agent 项目，强调不依赖云端服务即可完成界面操作任务。
- 该方案与 MCP、RAG、tool calling、multi-agent 等常见 Agent 技术栈相关，但核心卖点在于端侧部署与隐私/离线可用性。
- GitHub 仓库提供实现细节，适合关注本地化 Agent、GUI 自动化与去云化架构的开发者参考。

### [Coinbase Built, Evaluated, and Post-Trained a Fraud Agent on Qwen3.5-9B](https://www.coinbase.com/en-gb/blog/part-one-how-coinbase-built-evaluated-and-post-trained-a-fraud-agent)
- Coinbase 在 Qwen3.5-9B 上构建、评估并后训练了一个欺诈检测 agent，展示了将通用基础模型专用于反欺诈场景的完整流程。
- 该 agent 集成了 MCP、RAG 与 tool calling 能力，使模型能够调用外部工具与知识库，从而提升欺诈识别与研判的准确性和可解释性。
- 这一实践体现了 multi-agent 架构在企业安全场景的应用潜力，通过分工协作的 agent 系统增强对复杂欺诈行为的自动化响应能力。

### [Show HN：评估并改进你的 agent steering](https://news.ycombinator.com/item?id=50081857)
- Agent Desk 是一款本地 macOS 应用，让你跨 Claude Code、Cursor、Codex、GitHub Copilot、Kiro、Antigravity 等主流编码 agent 浏览会话，按项目查找、回顾对话，并检视 rules、skills、hooks、subagents 等完整 harness 配置。
- Session Intelligence 是一个 Go 库，用你自己的 LLM 结构化和分析会话 transcript，帮助识别缺失上下文、重复纠正、会话是否达成目标、精力浪费点，并发现泄露的凭证与 PII；两个项目均为 MIT 许可。
- 两者可组合使用，从而更好地理解你的 agent steering 习惯；这也为 RAG、tool calling、multi-agent 乃至 MCP 相关实践提供可观测性与评估基础。

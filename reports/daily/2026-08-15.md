## Research and engineering

### [Flownie – Open and Visual Data Workflow Platform with AI Agent Assistance](https://flownie.com/)
- Flownie is an open and visual data workflow platform that leverages AI agents to assist in designing and executing complex data pipelines.
- It supports MCP (Model Context Protocol) for seamless integration with external AI models and tools, enabling context-aware automation within workflows.
- With built-in RAG (Retrieval-Augmented Generation) and tool calling capabilities, Flownie enables multi-agent collaboration to streamline data processing and analysis.

### [Talos AI Agent Super Secure](https://github.com/talos-kernel/talos)
- Talos 将 MCP 集成到内核级安全层，以严格管控 AI agent 的工具调用，确保 tool calling 在最小权限下执行。
- 通过 RAG 增强上下文理解，同时利用 multi-agent 架构实现安全策略的分布式决策，防止单点故障。
- 每个 agent 的 MCP 通信均被加密和审计，结合主动威胁检测，提供超安全的 AI 操作环境。

### [Show HN: Embassia – LLM Search Console – Web crawlers talk to your site's agent](https://embassia.com)
- Embassia integrates an agent into your website that allows ChatGPT, Claude, Perplexity, and other LLM crawlers to engage in direct conversations, moving beyond superficial queries to capture deep user intent.
- This tool acts as a search console for the LLM era, providing insights into what visitors are truly curious about by transforming static web scraping into interactive, agent-driven dialogues.
- By turning passive crawlers into active agents, Embassia enables you to shape your website and product based on real LLM and user intent, bridging the gap between static content and dynamic understanding.

### [Lightweight Task agent – checkable receipts](https://github.com/GCLprimary/PAT)
- 该轻量级任务代理通过可检查的收据机制，确保每次工具调用（如MCP）的执行结果均被记录并验证，提升透明度。
- 集成RAG（检索增强生成）以动态获取上下文，结合tool calling（工具调用）实现多步骤任务分解与执行。
- 支持multi-agent（多代理）协作，每个子代理负责独立任务，并共享结构化收据以协调最终结果。

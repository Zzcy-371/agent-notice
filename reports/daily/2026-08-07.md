## Research and engineering

### [piclaw – Pi coding agent in a Technicolor web trenchcoat](https://rcarmo.github.io/projects/piclaw)
- piclaw 将树莓派转化为一个炫彩的编码代理（Pi coding agent），集成 MCP 和 RAG 技术，为 Web 开发提供上下文增强的智能辅助。
- 通过 tool calling 与 multi-agent 协作，piclaw 能够在不同代理间分配任务，调用外部工具，实现高效的编码、调试和部署流程。
- 这款工具以“Technicolor web trenchcoat”为比喻，强调其鲜艳的界面设计和强大的 Web 集成能力，使得在树莓派上进行 AI 驱动的开发变得直观且炫酷。

### [Show HN: Selvedge – an append-only log of what your AI agent already rejected](https://github.com/masondelan/selvedge)
- Selvedge 是一个只追加的日志系统，记录 AI agent 拒绝的决策，增强透明度和可追溯性。
- 它通过 MCP 集成，无缝接入现有 AI 工具链，支持 tool calling 和 multi-agent 协作。
- 结合 RAG，Selvedge 能提供上下文感知的拒绝历史，帮助优化 agent 行为。

### [Agent Plugins](https://agent-plugins.org)
- MCP（模型上下文协议）为Agent插件提供标准化接口，实现与外部工具和数据的无缝集成。
- 通过RAG（检索增强生成）技术，Agent插件能够动态获取知识库信息，提升回答准确性和时效性。
- 结合tool calling和multi-agent架构，Agent插件支持复杂任务分解与协同执行，增强系统整体能力。

### [自行构建 Agent 基础设施的代价](https://twitter.com/harsehaj/status/2079593790814527998)
- 自建 Agent 基础设施涉及 MCP、RAG、tool calling 和 multi-agent 编排等复杂组件，需投入大量工程资源。
- 相比使用现成框架，自建方案在灵活性上占优，但需自行处理可扩展性、安全性和维护成本。
- 在快速迭代的 AI 领域，自建基础设施可能导致技术债务，除非团队有足够能力持续跟进最新进展。

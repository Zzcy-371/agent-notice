## Research and engineering

### [VSCode silently switches to Microsoft models, ignoring BYO agent configuration](https://github.com/microsoft/vscode/issues/340651)
- 开发者发现 VSCode 在未告知的情况下静默切换到 Microsoft 模型，覆盖了用户自带的 agent 配置。
- 该问题影响依赖 model 选择进行 MCP、RAG 与 tool calling 的工作流，可能破坏 multi-agent 编排的一致性。
- 相关讨论在 GitHub issue 与 Hacker News 上展开，关注点集中在透明性与 BYO 配置的可持续性。

### [Show HN: Woodpecker – 用 Pi 和用户脚本构建的浏览器 agent](https://news.ycombinator.com/item?id=50016052)
- Woodpecker 由 Oakery 打造，可重新组织任意网站并自动化日常 workflows；通过 Jev connector 接入 Discord，把日常对话中的用户反馈分类为 bug 报告、feature request 或性能问题，进而生成产品 roadmap。
- 官方 demo 展示了 Discord 频道管理流程，用户也可将同一套 tool calling 思路用于过滤 X 信息流、对 HN 帖子做分类等场景，体现浏览器 agent 在真实网页上的通用性。
- 该项目基于 Pi 与 user scripts 实现，发布者在 HN 上征集反馈与其他希望支持的 workflows，当前获 5 分、0 条评论，尚未涉及 MCP、RAG 或 multi-agent 的公开细节。

### [通过模拟合成：可扩展智能体-系统交互生成连贯企业数据](https://arxiv.org/abs/2610.10549)
- 提出 Synthesis Through Simulation（STS）无 schema 数据合成范式，LLM agent 在模拟企业环境中通过 policy-enforcing API 执行操作生成数据，借助 RAG 与 tool calling 保证结构性有效。
- 通用填充器 Generalist Populator（GP）作为领域无关 agent，在十个环境中取得 0.88 平均边际保真度与 100% 约束满足率，且无需访问数据库 schema。
- 统计合成器因种子数据需求在七个环境中不适用，具备 schema 权限的 agent 在航空环境紧耦合工作流中失败 82% 轨迹；STS 框架、全部环境与生成数据集已开源，支持 multi-agent 扩展。

### [Agent-Controlled Forgetting for Tool-Using Agents: Reversible Context Curation in Practice](https://arxiv.org/abs/2610.10590)
- 论文研究 tool-using agents 的 agent-controlled forgetting：acting model 选取已观察到的 tool results，用简短 note 在原位置替换，并将原始内容保存在可恢复归档中，无需任务特定训练；Python harness 提供批量归档与显式 recovery，同时保护 user instructions 和 assistant messages。
- 在 OpenTelemetry 调试案例加一个无关实现任务中，该方法 provider-reported prompt tokens 为 231,951，而保留完整历史为 912,492，累计 input tokens 减少 50%，预估 API 成本 USD 1.28-1.44 对比约 USD 4.38；但请求更多、耗时增加 17%，且两组仅通过两案例 primary behavioral oracle，均未完全满足 follow-up evaluation。
- 另一组应用开发任务没有带来 context 或成本节省，早期 continuation 在 context 减少的同时人工评估质量更低；这表明可逆 context 管理在 noisy tool-use trajectories 中可显著节省资源，但 workload dependence 是核心考量，也与 MCP、RAG、tool calling、multi-agent 等场景的上下文 curation 密切相关。

# Agent 技术日报 · 2026-11-28

## GitHub projects

### [opencode：开源编码智能体](https://github.com/anomalyco/opencode)
- 内置 MCP 支持，让编码智能体可直接连接外部工具与数据源
- 集成 RAG 与 tool calling，基于代码库上下文进行检索并调用工具完成任务
- 支持 multi-agent 协作，可拆分复杂开发任务并由多个智能体并行处理

### [taste-skill](https://github.com/Leonxlnx/taste-skill)
- 为 coding agents 注入审美品味：通过 art direction 与 reference images 引导生成，避免千篇一律的通用 AI 页面
- 将 browser check 纳入工具链，配合 tool calling 让 agent 在生成过程中实际验证页面视觉效果
- 适配 MCP 与 RAG 等工作流，并可作为 multi-agent 协作中的审美评审环节使用

### [Zero-egress ~0.04ms 6-layer deterministic firewall for AI agent payouts](https://news.ycombinator.com/item?id=50675433)
- 面向 AI agent 付款场景，采用零出网（zero-egress）设计，在本地完成全部校验，避免敏感数据外泄。
- 六层确定性防火墙以约 0.04ms 的延迟完成判定，适合在 MCP、RAG、tool calling 与 multi-agent 流程中做实时拦截。
- 发布在 HN 上，讨论热度极低（1 分、0 条评论），暂无社区反馈可供参考。

### [60,825 个开放问题：让你的 agent 去解决一个](https://lefttosolve.com/)
- lefttosolve.com 汇集了 60,825 个开放问题，可作为 agent 的任务来源，适合配合 tool calling 与 RAG 让 agent 检索并解决其中问题。
- 该思路与 multi-agent 协作模式天然契合：可将问题拆分后分配给不同 agent 并行处理，并汇总结果。

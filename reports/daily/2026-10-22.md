# Agent 技术日报 · 2026-10-22

## GitHub projects

### [agency-agents：触手可及的完整 AI agency](https://github.com/msitarzewski/agency-agents)
- 从 frontend wizards 到 Reddit community ninjas，每个 agent 都是具备个性、流程与可验证交付物的专业专家
- 支持通过 MCP、RAG 与 tool calling 将各领域 agent 接入真实工作流，按需组合完成从创意到落地的任务
- 可用 multi-agent 协作让 whimsy injectors 与 reality checkers 等角色互补，兼顾创意发散与结果校验

### [browser-use](https://github.com/browser-use/browser-use)
- 开源 Python 库，用于构建 AI browser agents，可与 MCP、RAG、tool calling、multi-agent 等能力结合。
- 提供 Browser Use Cloud：具备 stealth browsers，适合需要规避检测的网页自动化场景。
- 提供托管式 agent API，方便将浏览器智能体能力接入应用与服务。

### [orca](https://github.com/stablyai/orca)
- Orca 是管理一支 agent 舰队（如 Grok Bot、Claude Code）的工作平台，可用自己的订阅运行任意 coding agent。
- 支持 desktop、mobile 与 remote runtime，方便在不同环境中调度 agent 并保持一致的开发体验。
- 结合 MCP、RAG、tool calling 与 multi-agent 能力，Orca 让多 agent 协作与工具调用在统一平台上落地。


## Research and engineering

### [Scaling in Games: Continued Pre-Training For Embodied Agents In Diverse Virtual Worlds](https://arxiv.org/abs/2610.28698)
- 该研究通过 120 种训练配置（0.8B 至 27B 的四档模型规模、50 至 1,600 小时的六档数据预算、从仅 Minecraft 到多世界混合的 5 种数据混合方式）系统考察 CPT 在数据量、多样性与模型规模三个轴上的缩放规律，并用三级验证损失与游戏基准评估在语料内世界和相关/遥远未见世界上的性能与泛化。
- 结果显示：数据量提升语料内表现，多样性促进向相关世界的迁移但对遥远世界增益有限；单世界训练下模型规模提升数据效率却对遥远世界泛化更差；训练呈现早期以跨世界广泛收益为特征的 interface 阶段和后期收益收窄至语料内与相关世界的 world 阶段，并拟合出验证损失与数据量、多样性、模型规模的经验缩放律。
- 模型在 3D 世界中与 Minecraft 专家模型及前沿模型相比具竞争力，并在实时场景表现最佳；但模仿学习的局限与遥远世界的持续差距表明，构建通用具身智能体需要超越 continued pre-training 的更强训练阶段（如引入 MCP、RAG、tool calling 或 multi-agent 等机制）。

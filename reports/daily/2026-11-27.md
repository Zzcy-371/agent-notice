### [Show HN：Piton Lockfile 与面向 MCP/coding agent 的静态供应链扫描器](https://github.com/tony-stark2025/piton)
- Piton 为 MCP 与 coding agent 生态引入 Lockfile 机制，用于锁定依赖版本并提升可复现性。

- 项目也关注 RAG 与 multi-agent 等用法下的依赖治理问题，代码开源于 GitHub。

### [Confidence scores for gated automation of large language models](https://arxiv.org/abs/2611.33394)
- 该工作用监督学习训练模型预测 LLM 生成答案的正确性，从而支持自动化的 confident responses、并将不确定答案路由给人工审核，用于 gated automation。
- 方法上在冻结 LLM backbone 的最后一层 hidden state 上拟合线性 confidence score head，并以 text-only metamodels 作为闭源模型的替代方案；实验基于单个 2B 参数 backbone，答案约 98% 为 SQuAD、其余为 TruthfulQA。
- confidence score head 在多个 baselines 上表现最佳，在高准确率目标下自动化的工作负载比例最大；prompted confidence scores 看似 calibrated 却缺乏阈值化所需的分辨率，且向未见数据集的 transferability 一般，但该 head 仍最稳健，并可扩展到 safety 或 compliance 等属性的 gating。

### [Partial Routing：基于轨迹调优的委派机制，实现资源高效的 Agentic 工作流](https://arxiv.org/abs/2611.33402)
- Partial routing 让前沿 lead 模型在执行中把合适的子任务委派给更便宜的 worker 模型，无需训练任一模型；其依据来自对两者历史运行中重复子任务的质量与成本测量，并用参数 δ 控制委派程度。
- 在 ViBench 与 Terminal-Bench 4.0 的留出任务上，partial routing 的平均任务表现优于单独 lead 和 task-level routing；δ=0.75 时，ViBench 分数从 70.2 升至 78.5 且成本降低 19%，Terminal-Bench 通过率从 54% 升至 61% 且成本相近。
- 仅向 lead 提供子任务分解、不引入 worker，也能在两个基准上降低成本并提升 Terminal-Bench 通过率，表明对历史运行的分析能以很小的成本与实现开销支持更高效的规划与 delegation，并与 MCP、RAG、tool calling、multi-agent 等机制互补。

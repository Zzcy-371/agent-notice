## Research and engineering

### [缩小分析到设计的差距：面向自驱动实验室的授权约束型智能体](https://arxiv.org/abs/2611.25043)
- 提出一种架构，将智能体接入 DMTA 循环的 Analyze-Design 接口，实现由智能体驱动的测量选择与数据解释，同时确保改变状态的操作经过授权、验证与可审计。
- 在有机染料合成的氧化剂筛选活动中，于 LC-MS 仪器上验证：智能体提交测量任务、解释 MS 与 DAD 数据、标记失败实验并生成氧化剂排序，结果与脚本化峰积分一致，且经有机化学家确认。
- 在回放归档数据的模拟环境中，该智能体平均约在第 7 次进样测得最高产条件（随机顺序平均为 14.5 次），并在进样上限不少于 8 次的每轮活动中均识别出该条件，表明其可在行动受限且可验证的前提下弥合分析到设计的差距。

### [CodeReAct：面向工业维护工单管理的 LLM-Agentic 框架](https://arxiv.org/abs/2611.25070)
- CodeReAct agent 通过自然语言交互完成知识抽取、资产状态摘要与工单推荐，并将工业数据标准化为业务对象（BOs），再由分析型函数 API 调用支撑多年度工单、告警与异常分析。
- 该 agent 采用 Thought-Action-Observation 的推理执行循环来自动化数据科学家式的复杂分析，其中 Action 阶段生成可执行代码，替代人工编码；可与 MCP、tool calling、RAG、multi-agent 等工程化组件衔接。
- 以冷水机组维护为案例，框架有效解析人类话语并产出可指导决策的洞察，减少对数据科学家的依赖，并支持跨工业维护场景的自主函数生成与任务执行。

### [SailSearch：面向组合优化的智能体辅助发现](https://arxiv.org/abs/2611.25087)
- SailSearch 是一个由人类引导、由两个语言模型智能体协作完成的算法研究工作流，在 Market Split 与最大独立集（MIS）两个问题上给出了实证结果。
- 在 Market Split 上，其随机化算法在多个格基间搜索，将计算划分为枚举与持续的基约化两部分；在双核 CPU、24 小时截止条件下，每个实例跑十个随机种子，首次以纯 CPU 求解了 33 个此前开放的 QOBLIB 实例中的 18 个，每个种子在 156 个基准实例中解出 130 至 133 个。
- 在 MIS 上，其生成器将植入的 XOR 约束编码为带可证最优值的图；在 1,752 至 3,996 个顶点的七个实例上，被测求解器八小时运行返回的最好解仍比最优值差 5 至 15 个顶点。

### [BuggyMLE：用 bug 注入扩展机器学习工程难度](https://arxiv.org/abs/2611.25088)
- BuggyMLE 提出 Code Complexity Index（CCI），用仓库规模、依赖深度与补丁大小等十项结构特征预测八项公开编码基准的平均解决率（R²=0.951）；据此让 agent 对可运行的 ML 仓库注入受控变异，合成 6,600+ 个仓库变体与近 26 万行注入代码。
- 基于该框架构造的 BuggyMLE-Bench-Lite 是首个按难度分级、仓库级的 MLE-Bench Lite 变体；在 14 个模型上，最高解决率从最简单档的 95% 降至最难档的 9%，凸显 multi-agent、tool calling 与 shell 级仓库访问在 MLE 中的必要性。
- 作者还跨三个难度层级在 200+ 个 ML 仓库上合成训练课程，微调 Qwen3.5-9B 使其在 BuggyMLE-Bench-Lite 上比肩前沿模型，并迁移至 ML 之外：SWE-bench Lite 解决率由 24% 升至 33%，LiveCodeBench v6 pass@1 由 69% 升至 71%。

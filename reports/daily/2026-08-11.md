## Research and engineering

### [We Built Linear Agent](https://linear.app/now/how-we-built-linear-agent)
- 本文介绍了Linear Agent的构建过程，重点阐述了MCP（模型上下文协议）在集成外部工具和系统中的应用，使AI能够高效地操作项目管理数据。
- 通过RAG（检索增强生成）技术，Linear Agent能够从大量项目文档和代码库中检索相关信息，从而提供准确的上下文感知回答。
- 该智能体采用tool calling机制和multi-agent协作架构，通过多智能体分工负责不同任务（如问题分类、代码生成、任务调度），显著提升了工作流自动化效率。

### [Multi-agent version control with reactive feedback](https://lexifina.com/blog/adding-a-multi-agent-write-lock)
- 介绍了一种基于MCP的多代理版本控制机制，通过写锁和反应式反馈确保并发编辑的一致性。
- 利用RAG增强上下文感知，使各代理在提交变更前能动态检索相关信息，减少冲突。
- 结合tool calling实现自动化合并和冲突解决，多代理协同下提升版本控制效率和准确性。

### [Show HN: Opencodex, a free open-source coding agent for VSCode](https://github.com/matonhp5108/Opencodex)
- Opencodex is a free, open-source coding agent that integrates directly into VSCode, leveraging MCP (Model Context Protocol) to enhance contextual understanding.
- It supports RAG (Retrieval-Augmented Generation) to fetch relevant codebase information, improving the accuracy of generated code suggestions.
- With advanced tool calling and multi-agent orchestration, Opencodex enables collaborative problem-solving and efficient task automation within the IDE.

### [Wanno – AI builder, cloud agent and infra for your apps](https://wanno.dev/)
- Wanno serves as an AI builder that integrates MCP (Model Context Protocol) to enable seamless tool calling and orchestration for your applications.
- It provides a cloud-based agent infrastructure with built-in RAG (Retrieval-Augmented Generation) for enhanced knowledge retrieval and context-aware responses.
- Supporting multi-agent collaboration, Wanno simplifies deployment and scaling of AI workflows while managing underlying infrastructure for developers.

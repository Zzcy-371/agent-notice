## Research and engineering

### [Show HN: 用 Protoshot 闭环 UI 构建的 AI agent 循环](https://npmjs.com/protoshot)
- Protoshot 扫描项目的 CSS 文件和组件，只需编写少量 JSX 即可预览 UI，无需为查看界面效果而编排 agent-browser 或 puppeteer 实例。
- 相比启动浏览器编排流程，它提供更简单的配置方式，让 AI agent 的 UI 构建反馈循环更快闭合，也便于与 tool calling、MCP 等机制衔接。
- 该工具指向 RAG 与 multi-agent 场景下频繁预览界面的痛点，发布在 Hacker News 的 Show HN，目前 1 分、0 条评论。

### [Red-Teaming OpenAI's Internal Agent Monitoring Systems](https://metr.org/blog/2026-10-22-red-teaming-openai-agent-monitoring)
- METR 对 OpenAI 内部 agent 监控系统开展红队测试，重点评估针对 tool calling 与 RAG 流程的逃逸与规避手法。
- 测试场景覆盖 multi-agent 协同下的异常行为检测盲区，并检验 MCP 等工具接口在对抗性输入下的监控覆盖度。
- 文章总结了红队发现、监控失效模式及改进建议，HN 讨论区目前尚无评论。

### [Show HN: Omni Verify，我的 AI agent 必须等 Kane 核验每一项承诺后才能发布](https://github.com/DainoJung/omni-verify)
- Omni Verify 在 AI agent 对外发布内容前加入 Kane 核验环节，逐项检查其承诺是否兑现，未通过则不允许发布。
- 该项目以开源形式托管在 GitHub，面向 RAG、tool calling 与 multi-agent 流程中的可靠性问题提供验证思路。

## Research and engineering

### [Microsoft 发布 AI Agent 共享责任模型](https://learn.microsoft.com/en-us/azure/security/fundamentals/shared-responsibility-ai-agent)
- Microsoft 正式发布 AI Agent 共享责任模型，明确了在 AI Agent 生命周期中各方（如开发者、企业、云提供商）的安全与合规责任边界，涵盖数据、模型、工具及运行时环境。
- 该模型强调在 agentic AI 场景下，责任延伸至 RAG 数据源、MCP 工具调用、插件及多智能体协作中，需由开发者、企业和平台协同管理风险。
- 模型提出，在 tool calling 和 multi-agent 交互中，需实施持续监控、身份验证与访问控制，确保 AI Agent 的可信、安全与负责任部署。

### [Obsessing over AI Agent Harnesses](https://www.roderick.dev/writing/2026-08-28-obsessing-harnesses)
- 深入探讨 AI Agent harness 的设计哲学，强调 MCP（Model Context Protocol）在标准化工具调用与上下文管理中的核心作用。
- 解析 RAG（检索增强生成）与 tool calling 在 harness 中的集成模式，展示如何通过动态工具选择与外部知识检索提升 Agent 的推理能力。
- 探讨 multi-agent 协作框架下的 harness 架构，关注任务分解、信息共享与冲突解决机制，以实现高效的群体智能。

### [Show HN: Metis – 一个智能体框架，将 DeepSeek 提升至 Opus 级编码能力（82%）](https://github.com/Wholiver/metis)
- Metis 是一个智能体框架，通过 MCP 集成和 RAG 增强，将 DeepSeek 的编码能力提升至 Opus 水平（82%）。
- 支持复杂的 tool calling 和多智能体协作，实现高效的任务分解与执行。
- 开源项目，提供灵活配置，适用于自动化编程和复杂工作流。

## Research and engineering

### [针对 Claude Code 代理策略的最小权限 linter](https://www.npmjs.com/package/@cognitive-fab/polycheck)
- polycheck 是用于 Claude Code 代理策略的最小权限 linter，确保策略按最小权限原则配置。
- 它检查策略中定义的 MCP、RAG 和 tool calling 权限，限制代理对资源的过度访问。
- 支持 multi-agent 场景，验证各代理的权限边界，防止权限提升和横向移动。

### [We set up our cloud agent environment](https://cursor.com/blog/cloud-agent-environment)
- We deployed a multi-agent system to a cloud environment, leveraging MCP for secure Model Context Protocol-based tool calling.
- The cloud agents use RAG to access relevant knowledge from our internal documentation, enhancing their decision-making.
- Tool calling enables the agents to interact with external services, improving automation and workflow efficiency.

### [Vibe coded UI CI runner for your agent](https://github.com/hamza221/ActUi)
- ActUi 是一个为你的 agent 设计的 Vibe coded UI 持续集成运行器，允许通过自然语言描述来生成和运行 UI 测试。
- 它集成了 MCP（Model Context Protocol）和 RAG（检索增强生成），以增强 agent 对 UI 上下文的理解和生成能力。
- 支持 tool calling 和 multi-agent 协作，使多个 agent 能够协同工作，自动执行 UI 测试流程。

### [Best Agent Gateways for Healthcare Organizations 2026](https://www.mintmcp.com/blog/agent-gateways-healthcare-organizations)
- Healthcare organizations are adopting agent gateways to securely integrate AI agents with MCP (Model Context Protocol) and existing EHR systems, ensuring compliance with HIPAA and other regulations.
- Top gateways now support RAG (Retrieval-Augmented Generation) pipelines for clinical decision support, enabling real-time access to patient data, medical literature, and internal knowledge bases through unified APIs.
- Critical features include tool calling orchestration, multi-agent collaboration, audit logging, and policy-based access controls, which streamline clinical workflows and reduce operational overhead.

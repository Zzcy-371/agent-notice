## Research and engineering

### [Even More Deception: Objective Misalignment in Mixed-Motive LLM Multi-Agent Systems](https://arxiv.org/abs/2607.26120)
- 提出一个评估框架，利用狼人杀游戏测试LLM多智能体系统中的目标错位，通过改变单个智能体的目标而保持其角色不变，结合MCP和RAG技术分析内部推理与公开廉价谈话行为。
- 研究发现，目标错位在对抗性环境中会破坏整体结果，且不对称信息和专业角色会加剧这种影响，即使妥协的智能体发展出明显不同的推理策略，其公开行为仍难以察觉。
- 结果强调，即使细微的目标错位也会深刻影响集体决策，凸显了为基于LLM的多智能体系统（结合tool calling和multi-agent）制定有效缓解策略的必要性。

### [ClinLens: Towards Long-Horizon Coding Agents for Longitudinal Multimodal Clinical Data Science](https://arxiv.org/abs/2607.26155)
- 提出CLINLENS基准，包含200个可执行任务，覆盖五个链接的MIMIC资源（结构化电子健康记录、笔记、心电图、胸部X光片和超声心动图），并采用4x5分类法，跨越四种患者时间范围和五种分析能力。
- 采用程序优先的反向合成方法，将每个有界半原始包与评估者私有的参考工作流配对，检查所需工件、队列和时间语义及最终答案；在固定的126任务套件上，最强的模型-脚手架配置达到56.3%的scope-macro STRICTPASS，尽管EXECSUCCESS为100%。
- 结果显示，独立配置的编码代理可解决83/126任务，而五个适配GPT-4o-mini的生物医学系统最高仅达2.9%的scope-macro STRICTPASS，暴露了可运行提交与正确临床分析之间的巨大差距，强调需要长视野编码代理和MCP、RAG、工具调用及多智能体等技术的整合。

### [GuideSkill: Evolving Executable LLM Agent Skills for Guideline-Grounded Clinical Reasoning](https://arxiv.org/abs/2607.26160)
- GuideSkill 将临床指南编译为可执行函数，返回序数诊断支持评分，作为外部推理层，超越了传统的 RAG 或参数化吸收。
- GuideSkill-Evo 利用病例-诊断对优化技能，将金标技能覆盖率从 56.5% 提升至 99.5%，相对直接推理提高 18.49%，且不更新骨干模型。
- 通过 MCP 和多智能体协作，GuideSkill 使 LLM 能够动态分流诊断、匹配技能并融合排名，在四个基准上平均超过指南 RAG 13.45%，且专家评估确认其临床合理性。

### [GoGoTB: Agentic RTL Verification with Specification-Grounded Coverage Closure](https://arxiv.org/abs/2607.26181)
- GoGoTB 采用多智能体（multi-agent）架构，通过执行控制层与知识系统实现端到端验证闭合，结合 MCP 工具调用（tool calling）自动生成完整验证环境。
- 其覆盖闭合机制将每个覆盖点锚定到规格行为，利用 RAG 驱动的知识系统动态调用设计方法学知识，确保残留缺口可溯源并针对性修复。
- 在 8 个 RTL 设计上无需人工干预，环境生成成功率 100%，平均行/分支/翻转/功能覆盖率分别达 98.4%、97.2%、97.0% 和 83.2%，显著优于现有 LLM 方法。

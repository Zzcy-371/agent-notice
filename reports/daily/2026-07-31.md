## GitHub projects

### [opencode](https://github.com/anomalyco/opencode)
- opencode 是一个开源编码代理，支持 MCP 协议，允许与外部工具和服务进行标准化集成。
- 它内置 RAG 能力，能够从知识库中检索相关信息，增强代码生成和问题解决的准确性。
- 通过 tool calling 和 multi-agent 架构，opencode 可以并行调用多个工具并协调多个代理，完成复杂开发任务。


## Research and engineering

### [Fluent – Voice computer use agent for Windows (VLM and accessibility tree)](https://fluentforall.com/)
- Fluent 是一个面向 Windows 平台的语音驱动的计算机使用代理，结合视觉语言模型（VLM）与无障碍树（accessibility tree）技术，实现自然语言控制电脑操作。
- 该代理支持 MCP（模型上下文协议）和工具调用（tool calling），能够与外部工具和服务无缝集成，扩展自动化能力。
- 采用多智能体（multi-agent）架构，协调不同子任务，提升复杂操作的执行效率和容错性。

### [Show HN: Real Estate Agent Email List – 1.1M+ US Realtor Contacts](https://www.usagentleads.com)
- 提供全美50州超110万条房地产经纪人邮箱和电话的验证数据，支持按州定制采购。
- 结合MCP与RAG技术，实现数据检索与智能过滤，帮助用户精准定位潜在客户。
- 支持tool calling与multi-agent协作，自动化流程，提升营销效率。

### [ChatGPT 优化其智能体循环：Harness、API 与推理](https://blog.bytebytego.com/p/how-chatgpt-optimizes-its-agent-loop)
- 深入解析 ChatGPT 如何通过 Harness 集成 MCP 与 tool calling，实现高效的多智能体协作和外部工具调用。
- 探讨 API 设计在智能体循环中的关键作用，以及如何通过推理优化提升 RAG 检索和上下文理解的准确性。
- 揭示 multi-agent 架构下，ChatGPT 如何动态调度任务并平衡系统负载，从而增强整体响应速度与稳定性。

# Agent 技术日报 · 2026-08-17

## GitHub projects

### [skills](https://github.com/mattpocock/skills)
- 从.agents目录直接加载MCP工具配置，实现工程师环境的即时技能集成
- 通过RAG检索内部知识库，为tool calling提供上下文增强的决策支持
- 支持multi-agent协作调度，动态分配任务给最合适的技能代理执行

### [awesome-design-md](https://github.com/VoltAgent/awesome-design-md)
- 通过分析知名品牌设计体系的DESIGN.md文件，为项目引入设计规范，使编码代理（coding agents）生成匹配的UI界面。
- 整合MCP（模型上下文协议）与RAG（检索增强生成），智能检索设计文档并辅助代理理解设计意图，提升UI生成的一致性。
- 支持tool calling与multi-agent协作，将设计规范转化为可执行的开发指令，实现从设计到代码的高效流程。

### [codex](https://github.com/openai/codex)
- codex 是一个轻量级编码代理，直接在终端中运行，利用 MCP 和 tool calling 与开发环境无缝集成。
- 它支持 RAG 技术，能快速检索代码库或文档，提供精准的上下文感知建议。
- 通过多代理（multi-agent）协调，codex 能并行处理复杂任务，提升编码效率。

### [TradingAgents](https://github.com/TauricResearch/TradingAgents)
- TradingAgents 是一个基于多智能体 LLM 的金融交易框架，通过模拟真实交易团队协作，集成多种智能体角色进行市场分析、决策和风险管理。
- 框架利用 MCP（模型上下文协议）连接外部数据源和工具，结合 RAG 技术检索历史新闻、财报和宏观数据，增强 LLM 的金融领域知识。
- 支持 tool calling 实现实时数据获取、订单执行和策略回测，多智能体协作机制提升决策的一致性和鲁棒性，适应动态市场环境。

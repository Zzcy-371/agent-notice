# Agent 技术日报 · 2026-10-17

## GitHub projects

### [codex](https://github.com/openai/codex)
- 在终端中运行的轻量级 coding agent，直接通过命令行交互完成代码任务。
- 支持 tool calling 与 MCP，可调用外部工具并接入上下文资源，扩展编码能力。
- 可结合 RAG 与 multi-agent 模式，实现检索增强的代码理解与多代理协作开发。

### [open-design：首个协作式 AI 设计 Agent 工作空间](https://github.com/nexu-io/open-design)
- Local-first 且开源的协作式 AI 设计环境，团队可与 AI agents 在同一 workspace 中创建 prototypes、websites、apps、dashboards、presentations、images 和 videos。
- 支持在 workspace 内分享作品、交换反馈并共同迭代，把设计协作与 AI 生成整合到统一流程中。
- 可与 MCP、RAG、tool calling、multi-agent 等能力结合，扩展 AI 设计 Agent 的上下文获取、工具调用与多 Agent 协作场景。

### [Agent-Reach](https://github.com/Panniantong/Agent-Reach)
- 一个 CLI 即可让 AI agent 获得读取与搜索整个互联网的能力：支持 Twitter、Reddit、YouTube、GitHub、Bilibili、XiaoHongShu，零 API 费用。
- 为 MCP、RAG、tool calling 与 multi-agent 场景提供统一的联网检索入口，降低多源数据接入成本。
- 通过单一命令行接口整合多平台信息获取，让 agent 无需逐一对接各平台 API 即可扩展外部视野。


## Research and engineering

### [IneqAgent：用符号计算在 Lean 中完成智能体式不等式证明](https://arxiv.org/abs/2610.20681)
- IneqAgent 将 LLM 推理与符号计算结合，通过引理级 Monte Carlo Tree Search 协调引理构造、目标重写与符号后端选择，并用 Lean 反馈组装完整证明。
- 互补的 sum-of-squares、Bernstein 与 successive difference-substitution 后端为局部 Lean 证明生成精确证书，在四个基准上以 DeepSeek-V4-Flash 求解 186 题中的 175 题（94.09%）。
- 该方法在低 LLM 推理成本阈值下优于同骨干的 Direct Agent，并给出 Dittert 猜想四、五维的 Lean 验证强化及 Holens–Djokovic (4,4) 不等式的认证。

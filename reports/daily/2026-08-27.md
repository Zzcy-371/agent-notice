## Research and engineering

### [LangChain-AI/deepagents: agent harness](https://github.com/langchain-ai/deepagents)
- 为智能体提供标准化工具集，集成 MCP 以简化外部系统交互。
- 内置 RAG 能力，支持从知识库检索增强生成，提升回答准确性。
- 支持 tool calling 和 multi-agent 协作，构建复杂自动化工作流。

### [Show HN: I built an agent-first productivity bridge for all your agents](https://www.taskshell.app/)
- TaskShell 是一个专为 AI 代理设计的任务管理桥接层，通过 MCP（支持 stateless HTTP 和 SSE）实现代理与任务的无缝同步。
- 它支持多代理协同（如 Codex、Claude Code、OpenCode），并允许通过自然语言进行任务 CRUD 操作，无需切换上下文。
- 提供 Web 应用界面进行手动更新和实时监控，所有操作（人工或代理）均会同步记录。

### [Ask HN: What do you do when your AI coding agent is doing its job?](https://news.ycombinator.com/item?id=49461055)
- For developers with ADHD, maintaining focus while an AI coding agent works is challenging; some suggest breaking tasks into smaller, interactive steps using MCP or RAG to keep engagement.
- Using tool calling to pause and review each step can help, but may reduce efficiency; alternative approaches include pairing with a human or using multi-agent systems for parallel work.
- Others recommend using the idle time productively, such as reviewing code, planning next steps, or even taking short breaks to avoid burnout.

### [LLM Agents Using Simulation Models for Controlled Experiments](https://arxiv.org/abs/2608.23622)
- Introduces a multi-agent framework that enables LLM agents to conduct controlled experiments with scientific simulation models for pharmaceutical process design.
- Integrates MCP and tool calling to design experiments, execute comparative simulations, and interpret outcomes within a structured task representation.
- Demonstrates that simulation-integrated experimental reasoning with RAG and multi-agent collaboration yields more specific, correct, and helpful recommendations than language-only reasoning.

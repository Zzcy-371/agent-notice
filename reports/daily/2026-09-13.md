## GitHub projects

### [Agent-Reach：让 AI agent 拥有看遍整个互联网的眼睛](https://github.com/Panniantong/Agent-Reach)
- 一个 CLI 即可让 AI agent 读取并搜索 Twitter、Reddit、YouTube、GitHub、Bilibili、XiaoHongShu，零 API 费用，适合作为 tool calling 与 multi-agent 工作流中的统一数据入口。
- 为 MCP 与 RAG 提供跨平台实时内容源：agent 可抓取网页与社交平台信息，无需逐个平台申请 API key，降低检索增强生成的集成成本。
- 用统一命令行替代多平台 SDK，简化 AI agent 的互联网感知能力，便于在 multi-agent 系统中让不同 agent 共享同一套搜索与读取工具。

## Research and engineering

### [Show HN：我们为 Agent Teams 构建可共享的 Context Layer](https://github.com/volcengine/OpenViking)
- 该项目在 GitHub 上开源（volcengine/OpenViking），目标是让多个 Agent 共享同一层上下文，从而支撑 multi-agent 协作场景。
- 可共享的 Context Layer 有望统一管理 MCP、RAG 与 tool calling 所需的上下文与工具信息，减少各 Agent 之间的重复配置与状态不一致。
- HN 讨论热度较低（1 分、1 条评论），实际效果、与其他方案（如 RAG 管线、Agent 框架）的差异仍有待社区验证。

### [Elephant-Goldfish Model（Agent Skill）](https://github.com/google/elephant-goldfish-model)
- 来自 Google 的 GitHub 项目 Elephant-Goldfish Model，以 Agent Skill 形式发布，相关讨论见 Hacker News。

### [Uncensored LLMs in agent loops: 31 models, 5 tasks, most fail half the time](https://openuncensored.com/blog/uncensored-models-in-agent-loops)
- 对31个模型在5项任务上的agent loop测试显示，多数无审查模型在接近半数情况下失败，尤其在需要稳定tool calling和结构化输出的步骤。
- 该评测聚焦真实agent循环中的可靠性，而非单轮能力；失败模式多与工具调用错误、RAG检索后处理失衡以及指令遵循漂移相关。
- 文章为构建multi-agent或无审查LLM流水线的实践者提供参考：选型时需关注长循环稳定性与工具反馈的容错，而不只看基准分数。

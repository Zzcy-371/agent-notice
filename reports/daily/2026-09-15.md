# Agent 技术日报 · 2026-09-15

## GitHub projects

### [ponytail](https://github.com/DietrichGebert/ponytail)
- 让 AI agent 像房间里最懒的资深工程师一样思考：最好的代码，是你从未写过的代码。
- 通过 MCP 接入现有工具链，用 tool calling 直接复用成熟能力，避免重复造轮子。
- 结合 RAG 检索历史决策与代码库上下文，并借助 multi-agent 分工评审，只写真正必要的最小实现。

### [awesome-llm-apps](https://github.com/Shubhamsaboo/awesome-llm-apps)
- 汇集 100+ 免费开源的 AI Agents、Agent Skills 与 RAG Apps，覆盖多种应用场景与实现范式。
- 涵盖 MCP、tool calling、multi-agent 等关键能力，方便开发者快速参考与搭建可运行的智能体应用。
- 提供丰富的 RAG 应用示例与开源资源，助力从原型验证到生产落地的快速迭代。

### [cc-switch](https://github.com/farion1231/cc-switch)
- 跨平台桌面 All-in-One 助手，统一管理 Claude Code、Codex、OpenCode、OpenClaw、Grok Build 与 Hermes Agent。
- 面向 MCP、RAG、tool calling、multi-agent 等能力提供集中式配置与切换体验。
- 唯一官方网站为 ccswitch.io，请通过该域名获取正式版本与更新。

### [caveman](https://github.com/JuliusBrussee/caveman)
- 🪨 caveman 是一个 viral skill + proxy，用「少 token 办大事」的思路把 coding agents 的输出压缩成 caveman 风格，节省 65% tokens。
- 它通过改写 agent 的 response 层来降本，不改变底层 MCP、RAG、tool calling 或 multi-agent 编排能力，适合直接接入现有 coding agent 工作流。
- 对长链路 multi-agent 与频繁 tool calling 场景尤其有效，可显著降低上下文膨胀与 API 成本，同时保持代码任务的语义可执行性。

## GitHub projects

### [hermes-agent](https://github.com/NousResearch/hermes-agent)
- 与开发者共同成长的 agent 框架，原生支持 MCP、RAG、tool calling 与 multi-agent 协作。
- 内置可扩展的 MCP 工具接入与 RAG 检索增强，让 agent 能安全调用外部工具并基于私有知识作答。
- 支持 tool calling 与 multi-agent 编排，随项目复杂度演进逐步扩展能力边界。


## Research and engineering

### [SignafAIde：在 AI agent tool calls 运行前检查，支持离线验证](https://github.com/AIME-TECH-UK-LIMITED/signafaide-sdk)
- 为 AI agent 的 tool calls 提供运行前检查机制，可在执行前拦截和验证工具调用。
- 支持离线验证，适合需要在无网络或受限环境中运行 MCP、RAG、multi-agent 等场景。
- 项目以 SDK 形式发布，便于集成到现有 agent 工作流中。

### [Show HN：Harny — 专为小型/本地 LLM 调优的 VSCodium/VS Code AI 编程代理](https://harny.dev/)
- Harny 是一个面向 VSCodium 与 VS Code 的 AI coding agent，重点针对小型和本地运行的 LLM 进行优化
- 项目针对资源受限的本地模型调整了 tool calling、上下文管理与 RAG 流程，降低对大型云端模型的依赖
- 借助 MCP 与 multi-agent 架构，Harny 可在编辑器内组织多步编码任务，同时保持本地化与可扩展性

### [Show HN：AI Agent 基础设施与内存压缩规范](https://github.com/grfdsasdvef/awesome-ai-agent-infrastructure)
- 该仓库汇总了构建 AI Agent 的基础设施资源，涵盖 MCP、RAG 与 tool calling 等组件的集成方式。
- 重点提出内存压缩（memory compaction）规范，用于在长上下文与 multi-agent 协作场景中控制状态规模与成本。
- 适合作为 AI Agent 工程化落地的参考清单，但目前 HN 讨论热度极低（1 分、0 条评论）。

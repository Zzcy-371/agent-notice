## Research and engineering

### [Show HN: Agent Tunnels – coding agents collaborate across companies](https://agenttunnels.com/)
- Agent Tunnels 通过 MCP 实现跨公司编码智能体安全协作，让 AI 直接对话，无需人工在 Slack 中来回粘贴代码片段。
- 集成 RAG 与 tool calling，智能体可访问对方知识库并调用工具，自动解决集成问题，显著减少人工介入。
- 为 SDK/API 团队提供 multi-agent 协作新范式，替代传统“双 Agent + 双人类 + 单 Slack 线程”的低效流程。

### [Show HN: 让编码代理在不离开浏览器的情况下修复 Web UI 问题](https://github.com/montanaflynn/agent-feedback)
- 通过 MCP 与浏览器集成，编码代理直接获取 UI 反馈并修复问题。
- 利用 RAG 检索相关代码上下文，提高修复准确率。
- 支持 tool calling 和多代理协作，自动化处理 UI 缺陷。

### [Show HN: Undocking – 将智能体生成内容发布到网络](https://www.undocking.io/)
- Undocking 支持通过 MCP 协议连接各种 AI 智能体，实现从内容生成到网络发布的自动化流程。
- 利用 RAG 技术对知识库进行检索增强，确保生成内容的准确性和丰富度。
- 内置 tool calling 和 multi-agent 协作机制，可灵活调度多个智能体处理复杂任务并发布结果。

### [An AI agent with $15, 46 hours, and no way to send email](https://write.as/ih3l0kd78lpb1)
- 利用仅有的15美元预算和46小时时间，构建一个AI代理，并通过MCP（模型上下文协议）集成外部工具，实现自动化任务。
- 结合RAG（检索增强生成）技术，让AI代理能够从有限的数据源中检索信息，提升决策准确性，同时通过tool calling调用外部API执行操作。
- 在无法发送电子邮件的情况下，设计multi-agent（多代理）协作系统，通过其他通信方式（如HTTP请求）完成目标，展示AI代理的适应性和创造性。

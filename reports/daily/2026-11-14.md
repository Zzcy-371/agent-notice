## GitHub projects

### [ponytail](https://github.com/DietrichGebert/ponytail)
- 让 AI agent 像房间里最懒的资深开发者一样思考：能少写一行就少写一行。
- 最好的代码是你从未写过的代码，优先避免不必要的实现与复杂度。
- 适用于 MCP、RAG、tool calling、multi-agent 等场景中的 agent 行为约束。

### [caveman：用穴居人式表达为 coding agents 节省 65% token](https://github.com/JuliusBrussee/caveman)
- 通过 caveman 风格压缩提示词与输出，减少约 65% token 消耗，适用于 coding agents 的日常调用与上下文管理。
- 可作为 proxy 层接入现有 agent 工作流，在不改变 MCP、RAG、tool calling 与 multi-agent 编排逻辑的前提下降低推理成本。
- viral skill 定位强调简单直接：少 token 也能完成 trick，适合对延迟和费用敏感的开发者快速试用。

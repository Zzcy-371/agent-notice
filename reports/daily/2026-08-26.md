## GitHub projects

### [hermes-agent](https://github.com/NousResearch/hermes-agent)
- hermes-agent 是一个可成长的智能代理，支持通过 MCP（模型上下文协议）无缝集成外部工具与数据源，实现动态 tool calling。
- 内置 RAG（检索增强生成）能力，能够从知识库中实时检索信息，提升回答的准确性与上下文相关性。
- 采用 multi-agent 架构，允许多个专业代理协同工作，根据任务复杂度自动分配角色，实现灵活、可扩展的智能交互。


## Research and engineering

### [Ora benchmarks every major AI agent on Vercel – Customers](https://vercel.com/customers/how-ora-benchmarks-every-major-ai-agent-on-vercel)
- Ora benchmarks every major AI agent on Vercel, leveraging MCP for standardized tool integration.
- The benchmarking process incorporates RAG to evaluate retrieval-augmented generation capabilities.
- It includes tool calling and multi-agent orchestration scenarios to assess performance comprehensively.

### [Show HN: Agent Purge – Scrub any mention of anything agent related](https://news.ycombinator.com/item?id=49442369)
- Agent Purge 是一款浏览器扩展，支持 Chromium 和 Firefox，可自动清除网页中所有与“agent”相关的内容，包括 AI agent、RAG、tool calling 和 multi-agent 等术语。
- 该工具旨在帮助用户过滤掉过度使用的“agent”术语，恢复干净的阅读体验，同时避免干扰其他正常内容。
- 可通过 Chrome Web Store 和 Firefox Add-ons 安装，适合那些对 AI 术语感到厌倦的用户。

### [The AI Health Agent That Will Know Me for Life](https://williamtp.substack.com/p/the-ai-health-agent-that-will-know)
- 采用 MCP（模型上下文协议）与健康数据源无缝集成，让 AI 智能体随时安全访问个人健康记录。
- 通过 RAG（检索增强生成）精准引用医学知识，并结合 tool calling 调用检查、用药提醒等服务，提供个性化、循证的健康建议。
- 以多智能体（multi-agent）架构协同管理长期健康档案，实现从日常监测到慢性病管理的终身连续关怀。

### [Navalia: 通过可验证任务合成与长程后训练推进 Cowork Agents](https://arxiv.org/abs/2610.26887)
- Navalia 以企业财务报告为数据源，通过语义选择证据并构建可执行计算链，生成带可追溯证据与真实数据依赖的分析任务，再经独立 LLM 审核与程序化检查验证答案正确性。
- 验证后的任务用于轨迹收集、冷启动 SFT 与 RL，提升长程任务执行能力；该流程可与 tool calling、multi-agent 等 Cowork 能力结合。
- 以 Qwen3.6-35B-A3B 初始化的 Navalia 在 OfficeQA Pro、FinSearchComp、Finance Agent Benchmark、APEX-Agents-AA 与 Workspace-Bench-Lite 五个基准上均优于基座模型，并泛化到通用办公任务。

### [MedPAO-Assist：面向放射报告结构化的边缘可部署、模态感知 Agentic AI](https://arxiv.org/abs/2610.26913)
- 采用 multi-agent 架构与 Extract-Ground-Generate 范式，在 0.6B 参数级 Small Language Model 上完成概念抽取、SNOMED-CT grounding 与结构化报告生成，全程无需键盘输入、外部 API 调用或联网。
- 通过异步多线程执行流水线，在标准笔记本 CPU 上仅需约 3.3 GB 峰值 RAM，平均端到端延迟约 31 秒，支持 Chest X-ray、Chest CT、Abdomen CT 与 Brain MRI 四种成像模态。
- 系统逐阶段评估概念抽取、本体 grounding、概念分类与硬件性能，并加入语音驱动的人在回路纠错，形成面向数据隐私与离线场景的“no-touch”放射报告工作流。

### [DataPraxis：通过已验证工作区演化扩展分析任务](https://arxiv.org/abs/2610.26924)
- DataPraxis 提出基于已验证工作区演化的分析任务合成框架，逐步用经过验证的发现与工件丰富工作区，再继承并组合工作区以挖掘更深层问题。
- 该框架在演化过程与任务组装后双重验证分析结果，并据此构建 DataPraxis-5K（5,000 条跨领域、多输出格式的已验证轨迹）用于训练 DataPraxis-27B 与 DataPraxis-35B-A3B。
- DataPraxis-27B 在 DABStep 上取得 55.11、在 JobBench 上取得 51.9，匹配或超越 GLM-5.2 等前沿模型；数据集已在 Hugging Face 开放。

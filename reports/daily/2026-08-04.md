### [Agent needs a computer, not a container – introducing Cloudflare/computer](https://blog.cloudflare.com/cloudflare-computer)
- Cloudflare/computer 为 Agent 提供了一个完整的计算环境，而非传统的容器，从而支持更复杂的 MCP 和 RAG 任务。
- 该平台通过 tool calling 和 multi-agent 协作，使 Agent 能够灵活调用外部工具并协同工作，提升任务执行效率。
- 相比容器限制，Cloudflare/computer 提供了更强的隔离性和资源管理，适合运行需要持久状态或系统级操作的 Agent。

## Research and engineering

### [计算机使用型 agent 的任务完成速度有多快？](https://cuaspeedrun.com/)
- cuaspeedrun.com 以“speedrun”形式衡量 computer-use agent 完成任务的速度，关注端到端执行效率而非单纯准确率。
- 速度评估与 MCP、RAG、tool calling、multi-agent 等能力耦合：工具调用开销、检索延迟和多 agent 协作会直接影响完成时间。
- 在 Hacker News 讨论中该方向被视作 agent 评测的新维度，当前帖子仅 2 分、0 条评论，尚未形成广泛讨论。

### [Gloss – 标注实时代码并向 agent 提供反馈](https://github.com/ryanbrunner/gloss)
- Gloss 允许开发者在运行中的实时程序里直接添加标注，把对代码行为的观察转化为可供 agent 使用的结构化反馈。
- 与依赖 RAG 检索静态文档或历史日志的方案不同，Gloss 将人机协作的重点放在运行时上下文，减少 agent 对代码意图的猜测。
- 该工具可与 MCP、tool calling 等机制结合，让单 agent 或 multi-agent 系统在执行任务时接收实时标注，从而迭代修正行为。

### [Show HN: Television——为你的 agent harness 打造的开源 GUI](https://television.run/)
- Television 是来自 Telepath 团队的开源项目，为你的 agent harness 提供一个干净、美观的 GUI，用作创建和协作处理 artifacts 的可视化空间，支持 Claude Code、Codex、Hermes、OpenClaw、Pi、OpenCode 等任意 harness，并复用你 agent 已有的 inference provider。
- CLI 与轻量 server 安装在 agent harness 运行处（目前支持 Linux/macOS），连接到 macOS 客户端应用（浏览器也可用但有少许限制），一组 skills 会告诉 agent 如何把 artifacts 放到你的 TV 屏幕上并持续修改，像 sidecar 一样工作。
- 团队认为个人计算界面的未来不只是 chat，artifacts 是超越 chat 的第一步，用户应当真正拥有自己的 artifacts，整个 UI 和 artifacts 均可主题化，目前项目仍处早期并采用端到端完全 spec 驱动的开发流程。

### [paperclip](https://github.com/paperclipai/paperclip)
- 开源的团队级 agent 管理应用，帮助你在工作中统一编排和监控各类 agent。

## Research and engineering

### [Show HN: Proc-CLI – 面向 agent 的进程与端口管理命令行工具](https://proc-cli.com/)
- Proc-CLI 是一个 agent-friendly 的 CLI 工具，用于进程与端口管理，可通过结构化输出方便地与 MCP、tool calling 集成。
- 该工具可作为 multi-agent 工作流中的基础组件，帮助 agent 查询和操作进程与端口，并为 RAG 场景提供系统状态信息。
- 项目发布在 Hacker News 的 Show HN 板块，当前获得 2 分、0 条评论，详情见 proc-cli.com。

### [Phronix：面向 Agent 的能力中心学习范式](https://arxiv.org/abs/2610.31789)
- Phronix 通过 predictor-validator-corrector 循环，让 agentic harness 从自身执行中获取、验证并精炼可复用能力，借助 MCP tools、关联 skills 与 capability store 解决重复劳动，而非反复重新发现方案。
- 学到的能力可在首次尝试中解决重复任务，跨模型成功率达 93-95%，每个任务自动产生 7.6-30.8 个持久能力，且所需能力存在后新能力创建降至两个以下。
- warm-start 每任务仅消耗 0.38-0.40 百万 tokens，比单次基线尝试少三到四倍；在 1000 Genome Pegasus workflow 上通过全部 11 项正确性检查，并将两个低成本模型在 SWE-bench 上的解决率从 29% 和 27% 提升至 91% 和 87%。

### [PaperFormalizer：作者在环的研究论文 Lean 自动形式化](https://arxiv.org/abs/2610.31810)
- 将 LaTeX 源转换为陈述依赖图，用自然语言审计忠实性、歧义与正确性，再在 Lean 中对 Mathlib、领域库和个人 toolkit 进行形式化与证明。
- 在编码 agent（Claude Code 或 Codex）中运行，遇多义陈述即停并询问作者，以自然语言和 TeX 符号提交修复提案供接受、拒绝或改向，所有可能改变论文主张的决定留给作者。
- 输出含修订标注版论文、变更报告及 Lean 代码（每个声明链接到所形式化陈述），toolkit 随论文累积增长，作者可共享已验证论文以复用 Lean 代码。

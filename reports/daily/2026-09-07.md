## Research and engineering

### [From Matching Models to Recruiting Agents: A Systematized Narrative Review of AI Recruitment Systems, Evaluation, and Governance](https://arxiv.org/abs/2609.04286)
- 本文系统化叙述了AI招聘从匹配模型到招聘代理的演进，涵盖MCP、RAG、tool calling、multi-agent等关键组件，并分析了从相似性到互适性、从单一模型到复合工作流、以及从离线预测到基于证据评估的三大转变。
- 通过对40篇代表性文献的编码，本文区分了领域级、配对级、列表级、案例级、轨迹级和结果级证据，并指出行为标签混淆、数据局限性、输出评分掩盖流程缺陷等问题，同时强调隐私未直接评估。
- 提出了从评估证据到最强可辩护主张的分阶段映射，并倡导建立互惠、证据驱动、时间可控、选择性且可审计的招聘系统，以期在成本和风险约束下提升工作流的信息检索、不确定性保留和决策可争辩性。

### [Harbor Adapters and Harbor-Index: Infrastructure and a Curated Meta-Dataset for Large-Scale Agentic Evaluation](https://arxiv.org/abs/2609.04298)
- Harbor Adapters provide a unified evaluation infrastructure, porting over 80 benchmarks to assess arbitrary agents, with rigorous code review and parity experiments.
- Large-scale evaluation of 8 models across 54 benchmarks using Terminus-2 and 3 native harnesses enables broad analysis of agent capabilities and failure modes, including MCP, RAG, and tool calling.
- Harbor-Index, a curated meta-dataset of 82 tasks from 29 benchmarks refined via difficulty filtering and audits, ensures challenging and cost-effective evaluation, with the strongest model (GPT-5.5 with Codex) achieving 28.0% pass rate.

### [Iris: Climbing to the Search Frontier](https://arxiv.org/abs/2609.04304)
- Iris-mini and Iris-pro are search agents trained with a data pipeline that reverse-constructs multi-hop tasks from hyperlink structures, utilizing entity graph traversal, descriptive rewriting, and reference-model verification.
- Employing an SFT-RL climbing procedure, the policy is optimized against live search with reward judges and summarization inside the training cluster, integrating MCP-based tool calling and RAG-style evidence retrieval.
- State-of-the-art results on BrowseComp, BrowseComp-ZH, DeepSearchQA, and HLE are achieved via a single ReAct agent with context management, outperforming other open-source search agents.

### [Why Better Models Can Create Riskier Systems: Evidence from LLM Agents in Financial Markets](https://arxiv.org/abs/2609.04373)
- 本研究表明，提升单个大语言模型（LLM）的能力可能会降低而非提高系统层面的性能，原因是共享训练和架构导致模型行为更趋相似，产生无法分散的相关性，并形成不可分散的风险下限。
- 在金融市场中，使用不同通用能力的LLM交易员进行基于代理的模拟，发现前沿LLM表现出显著的相关行为，且相关性随能力增强而增加，这验证了模型能力提升反而可能增加系统风险的预测。
- 当LLM共享正确的推理时，增加代理参与度会降低市场风险；但当它们处于共同错误信息环境中时，相关性行为则成为负担，凸显了能力悖论：改进个体模型并不必然带来更好的系统级结果，而类似动态是否在其他领域出现仍是待解答的实证问题。

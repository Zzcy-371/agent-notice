## Research and engineering

### [Sentry: Learning to Recover from LLM Agent Failures at Test Time](https://github.com/nuglifeleoji/Sentry)
- Sentry 关注 LLM agent 在测试时出现失败后的自动恢复问题，尝试在推理阶段即时纠正错误，而非仅依赖离线训练。
- 该方法可能结合 RAG、tool calling 与 multi-agent 协作机制，让 agent 在失败后重新规划、调用工具或引入其他 agent 协助。
- 项目代码托管于 GitHub（nuglifeleoji/Sentry），目前 HN 讨论热度较低，仅 1 分、0 条评论。

### [Autonomous AI Agent Security Incidents of 2026 (Dataset and Defense Harness)](https://github.com/mars2021y-gif/autonomous-ai-agent-security-incidents-2026)
- 该数据集与防御 harness 汇总了 2026 年自主 AI agent 安全事件，覆盖 MCP、RAG、tool calling 与 multi-agent 等场景下的真实攻击案例。
- 防御 harness 提供可复现的评测流程，帮助开发者针对 tool calling 与 multi-agent 协作中的漏洞进行检测和加固。
- 项目在 GitHub 开源，HN 讨论帖已发布，目前点数 2、评论 0，适合关注 agent 安全的研究者参考。

### [LiteLLM Lens 如何在数千条 agent traces 中发现重复性失败](https://docs.litellm.ai/blog/lens-failure-patterns)
- LiteLLM Lens 聚合和分析数千条 agent traces，自动聚类重复出现的失败模式，而不是逐条排查。
- 该工具针对 MCP、RAG 和 tool calling 等复杂调用链定位不稳定环节，帮助识别 agent 反复出错的具体步骤。
- 在 multi-agent 场景中，它通过跨 trace 的模式对比发现系统性失败，为提示、工具或编排逻辑的改进提供依据。

### [通过自动诊断与技能发现训练数值智能](https://arxiv.org/abs/2610.03872)
- ADSD 采用诊断优先范式，先解释数值求解器性能不佳的根因，再据此指导发现合适的数值方法，避免盲目试错。
- 框架将诊断所得知识封装为可复用的 solver skills，把求解器改进转变为诊断、发现、实现的结构化流程，并与 RAG、tool calling 和 multi-agent 等能力相衔接。
- 在潮流方程、AC 最优潮流控制、刚性常微分方程和异质扩散 PDE 四个领域，ADSD 持续提升精度、鲁棒性与效率；在 GOC-500 潮流上平均误差降低近 71 倍，并可迁移到未见过的电网拓扑与运行工况。

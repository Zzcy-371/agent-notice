## Research and engineering

### [Evidence runtime for autonomous agent task management](https://grainulator.app)
- Evidence runtime 为自主代理提供任务管理与执行环境，集成 MCP 协议与 RAG 知识检索，增强上下文理解。
- 该运行时支持 tool calling 机制，使代理能够动态调用外部工具来完成复杂任务，提升自主决策能力。
- 通过 multi-agent 协作架构，实现任务分解与并行处理，提高任务执行的效率和可靠性。

### [SidePulse: Agent Status, at a Glance (LEDs in MacBook Pro SD Slot)](https://sidepulse.io/)
- SidePulse 通过在 MacBook Pro 的 SD 卡槽内嵌入 LED 灯，提供了一种直观的视觉方式，让用户一眼就能了解 MCP 代理的状态。
- 该工具集成了 RAG 和 tool calling 功能，使得代理能够实时检索信息并执行操作，而 LED 指示灯则清晰显示这些操作的进行状态。
- 在 multi-agent 系统中，SidePulse 通过颜色和闪烁模式区分不同代理的任务状态，帮助用户高效监控和管理多个并发代理的工作流程。

### [The robots.txt user-agent lines that do not name what they look like](https://ai-visibility.lastminutedealshq.com/robots-txt-user-agent-tokens)
- 探讨 robots.txt 中未明确命名的 user-agent 行，揭示其对 MCP、RAG 等 AI 代理抓取行为的潜在影响。
- 分析这些模糊的 user-agent 指令如何干扰 tool calling 和多代理系统的网络资源发现，导致抓取策略误判。
- 强调在 multi-agent 环境中，需借助标准化 user-agent 声明和精确规则，以提升 AI 代理的互操作性与合规性。

### [Hermes Kanban – Multi-Agent Profile Collaboration](https://hermes-agent.nousresearch.com/docs/user-guide/features/kanban)
- Harness the power of MCP to seamlessly integrate external tools and data sources.
- Leverage RAG for context-aware decision-making within each agent's profile.
- Orchestrate multi-agent workflows with tool calling and dynamic task assignment.

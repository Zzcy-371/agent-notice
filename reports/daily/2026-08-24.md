## GitHub projects

### [superpowers](https://github.com/obra/superpowers)
- MCP 驱动的技能框架，将 RAG 与 tool calling 融合，赋予 agent 自主执行复杂开发任务的能力。
- multi-agent 协作方法论，通过角色分工与任务编排，实现从需求到代码的高效交付。
- 提供可扩展的 tool calling 接口，支持动态 RAG 检索，使 agent 在真实项目中持续学习与优化。

### [claude-code](https://github.com/anthropics/claude-code)
- Claude Code is an agentic coding tool that lives in your terminal, understands your codebase, and helps you code faster through natural language commands.
- It supports MCP (Model Context Protocol) for extending its capabilities, integrates RAG for codebase understanding, and enables tool calling to execute routine tasks and handle git workflows.
- It facilitates multi-agent collaboration, allowing multiple instances to work together on complex coding tasks, explaining code, and managing version control efficiently.

### [paperclip: 开源智能体管理平台](https://github.com/paperclipai/paperclip)
- paperclip 作为开源应用，为工作场景中的智能体提供统一管理，支持多智能体编排与协作，简化复杂任务处理。
- 深度集成 MCP（模型上下文协议），实现智能体与外部工具的无缝对接，强化 tool calling 能力，提升自动化执行效率。
- 内置 RAG（检索增强生成）机制，结合知识库与实时数据检索，增强智能体的上下文理解与决策能力，适配企业级应用需求。


## Research and engineering

### [Locus – Deterministic Safe Rust AST Engine for Multi-Agent Coding Swarms](https://github.com/ahmadshady747-create/LOCUS)
- Locus is a deterministic, safe Rust AST engine designed specifically for multi-agent coding swarms, providing a robust foundation for concurrent code manipulation.
- It integrates MCP for standardized tool calling, enabling agents to perform precise AST operations while maintaining deterministic behavior and safety.
- By leveraging RAG and multi-agent collaboration, Locus enhances code generation and modification workflows, ensuring consistency and reliability across the swarm.

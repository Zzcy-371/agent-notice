# Agent 技术日报 · 2026-09-22

## GitHub projects

### [agency-agents](https://github.com/msitarzewski/agency-agents)
- 提供“指尖上的完整 AI 机构”，涵盖从前端专家到 Reddit 社区运营、从创意注入者到现实校验者等多样化角色。
- 每个 agent 都是具备个性、流程与可验证交付物的专业化专家，可按职能独立承担明确任务。
- 适合以 multi-agent 方式组合调用，并结合 MCP、RAG 与 tool calling 构建端到端协作工作流。

### [browser-use](https://github.com/browser-use/browser-use)
- browser-use 让 agents 直接操作浏览器，完成点击、输入、导航等交互任务，并将页面状态纳入决策循环。
- 通过与 MCP 和 tool calling 集成，browser-use 可以把浏览器动作暴露为可调用工具，供 RAG 或任务规划模块按需触发。
- 在 multi-agent 架构中，browser-use 常作为专用执行者，与其他 agents 分工协作，负责网页信息获取与端到端操作。

### [autoresearch](https://github.com/karpathy/autoresearch)
- AI agents 在单 GPU nanochat 训练上自动运行研究，全程无需人工干预
- 通过 MCP、tool calling 和 RAG 等机制，agent 自主设计实验、执行训练并分析结果
- multi-agent 协作进一步加速迭代，实现端到端自动化研究闭环


## Research and engineering

### [Doyouok – 面向 cron 任务和工作流的无 Agent 心跳监控](https://doyouok.com/)
- Doyouok 通过心跳机制监控 cron 任务和 workflow，无需部署 Agent，也不依赖 MCP 或 tool calling。
- 相比基于 RAG 或 multi-agent 的复杂可观测方案，这种无 Agent 方式更轻量，适合简单定时任务与流水线的可用性告警。
- 该工具在 Hacker News 上获得 1 分和 1 条评论，讨论热度较低，目前仍属早期项目。

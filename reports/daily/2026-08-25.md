## Research and engineering

### [I built an agent-skill that turns your texts into diagrams and BI-visuals](https://github.com/imshaikot/render-visual-skill)
- Developed an agent-skill leveraging MCP to convert natural language text into diagrams and BI visuals.
- Integrates RAG for context-aware generation, enhancing accuracy and relevance of visual outputs.
- Supports multi-agent collaboration for tool calling, enabling seamless creation of complex visualizations.

### [What languages are agent skills written in?](https://plicara.ai/research/agent-skill-languages)
- Agent skills can be implemented in various programming languages, with Python being the most common due to its rich ecosystem for AI and data processing.
- The choice of language often depends on the integration requirements, such as using JavaScript for web-based agents or C++ for performance-critical components.
- Frameworks like MCP allow skills to be written in any language, promoting interoperability, while RAG and tool calling are typically language-agnostic, but Python and TypeScript dominate in multi-agent frameworks.

### [The computer use verification skill that every agent needs](https://twitter.com/zachlloydtweets/status/2084411777354277027)
- MCP 智能体需具备 computer use 验证技能，确保工具调用安全可靠。
- RAG 和 multi-agent 架构下，该技能可验证环境状态，提升决策准确性。
- Tool calling 中集成验证步骤，有效防止错误操作，增强系统鲁棒性。

### [Session-migrate: 跨 Claude Code、Codex、Pi 迁移编码智能体会话](https://github.com/xhluca/session-migrate)
- Session-migrate 是一个开源工具，用于在不同编码智能体（如 Claude Code、Codex、Pi）之间迁移会话，保留上下文和状态。
- 它利用 MCP（模型上下文协议）实现标准化会话数据交换，并支持 RAG（检索增强生成）以增强迁移后的上下文理解。
- 通过 tool calling 和 multi-agent 协作机制，该工具简化了跨平台工作流，使开发者能无缝切换编码环境。

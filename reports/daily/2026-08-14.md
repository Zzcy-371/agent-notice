## Research and engineering

### [HoneyMatcha – 一个为你和你的个人代理打造的协调平台](https://honeymatcha.io/)
- HoneyMatcha 是一个协调平台，支持你与个人代理（personal agent）之间进行高效的任务分配与协作。
- 平台集成了 MCP（Model Context Protocol）与 RAG（检索增强生成），使代理能够访问丰富的上下文和信息源。
- 通过 tool calling 和 multi-agent 架构，HoneyMatcha 支持多个代理协同工作，实现复杂工作流的自动化与优化。

### [Agentic Scheduling = Apple Calendar + Apple Reminders + Claude Agent](https://github.com/hunterZh37/agentic-scheduling)
- 基于MCP构建智能调度系统，融合Apple日历与提醒事项，实现自然语言驱动的日程管理。
- 通过RAG增强上下文理解，让AI准确解析用户意图，自动安排会议、设置提醒。
- 支持tool calling与多智能体协作，动态协调资源，优化日程冲突，提升效率。

### [Show HN: Hearth – 一个共享家庭工作区，智能体可在其中构建应用](https://news.ycombinator.com/item?id=49292004)
- Hearth 是一个家庭共享工作区，集成了 MCP 与 RAG，智能体（agent）能基于家庭的笔记与上下文进行跨场景协作，类似带智能体的 Obsidian。
- 智能体不仅能管理日程和旅行应用，还能通过 tool calling 在家庭笔记之上构建并运行定制应用，支持多智能体协作与沙箱隔离，确保安全与最小权限。
- 基于 Playground 库构建，Hearth 强调隔离与策略层，未来将开源，目前处于 beta 阶段，适合家庭共同使用。

### [Show HN: Clixad – Free AI coding agent in the terminal, funded by an offerwall](https://clixad.io/)
- Clixad 是一款免费的终端 AI 编程助手，利用 MCP（模型上下文协议）与外部工具无缝集成，并支持 tool calling 实现自动化代码操作。
- 通过 RAG（检索增强生成）技术，Clixad 能够从代码库或文档中检索上下文，提供精准的代码建议和错误修复。
- 项目采用 multi-agent 架构，多个智能体协同处理复杂任务，并且通过 offerwall 广告模式实现免费使用，无需付费订阅。

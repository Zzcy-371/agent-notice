# Agent 技术日报 · 2026-08-30

## GitHub projects

### [opencode](https://github.com/anomalyco/opencode)
- opencode 是一个开源编码代理，支持 MCP 和 RAG，提供强大的工具调用能力。
- 通过 multi-agent 协作，opencode 能高效完成复杂编码任务，并集成多种工具。
- opencode 遵循开源理念，允许用户自定义和扩展，以适应不同的开发工作流。


## Research and engineering

### [The Rise and Fall of Agent Civilizations](https://www.dwarkesh.com/p/openai-huggingface)
- 探讨AI代理文明的兴衰，涉及MCP等协议在agent通信中的作用。
- RAG技术如何影响agent的知识获取与遗忘周期。
- tool calling与multi-agent系统如何塑造agent社会的协作与崩溃。

### [Sandbox.watch: Agent Sandbox Comparison](https://sandbox.watch/)
- Sandbox.watch 是一个比较不同 agent sandbox 的平台，帮助开发者评估和选择适合的沙箱环境。
- 该平台支持对 MCP（Model Context Protocol）和 RAG（Retrieval-Augmented Generation）等工具调用进行集成测试，确保 agent 在沙箱中的表现符合预期。
- 通过 tool calling 和 multi-agent 场景的基准测试，Sandbox.watch 提供详细的性能对比，助力开发者优化 agent 部署策略。

### [Subs，云原生智能体框架](https://substructure.ai/)
- 基于MCP（模型上下文协议）构建，确保与各种数据源和工具的无缝集成。
- 支持原生tool calling（工具调用），使多智能体（multi-agent）协同工作高效简洁。
- 利用RAG（检索增强生成）技术，提升智能体的知识获取与响应准确性。

### [智能体何时应该拥有控制流？](https://www.calm.rocks/blog/pipeline-vs-agent)
- 文章通过 pipeline 与 agent 的对比，讨论何时该让 agent 而非固定 pipeline 拥有控制流。
- 涉及 MCP、RAG、tool calling 与 multi-agent 等术语，属于 LLM 应用架构的设计权衡。
- 在 Hacker News 上引发讨论，探讨动态决策与可预测编排之间的取舍。

### [我用 AI QA agent 测试 Hacker News](https://hitest.ai/blog/demo-hacker-news)
- 作者让 AI QA agent 实际跑在 Hacker News 上，演示了自动化端到端测试流程。
- 文中结合 RAG 与 tool calling，让 agent 能理解页面上下文并调用工具完成交互。
- 该 demo 也展示了 multi-agent 与 MCP 的潜力，可扩展到更复杂的真实站点测试。

### [Ssrf-agent 1.0.5 通过两种地址写法访问 loopback](https://github.com/roshan-amble/ssrf-lab/blob/main/docs/findings/2026-09-13-ssrf-agent-bypass.md)
- 该研究记录了 ssrf-agent 1.0.5 中的一个 SSRF 绕过：用两种不同的地址表示法指向 loopback，从而绕过校验。
- 这类绕过手法常出现在 agent 的 tool calling 与 RAG 工具链中，当 URL 校验逻辑与实际网络栈解析不一致时，MCP 或 multi-agent 编排也可能被利用。
- 在 GitHub 的 ssrf-lab findings 中可查看完整分析与复现细节，相关讨论见 Hacker News 条目 50065190。

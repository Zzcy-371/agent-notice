## Research and engineering

### [Octomind：一个能在压缩后召回归档消息的编码 agent](https://github.com/muvon/octomind)
- Octomind 是一个编码 agent，重点解决上下文压缩导致历史消息丢失的问题，能在 compaction 之后召回已归档的消息。
- 该项目与 MCP、RAG、tool calling、multi-agent 等 agent 生态术语相关，可作为构建复杂编码工作流的参考实现。
- 文章发布在 GitHub 并同步到 Hacker News，目前获得 1 分、0 条评论，讨论度较低。

### [OpenFrontiers：开放研究问题集合与科学再发现基准](https://arxiv.org/abs/2610.37739)
- 构建跨学科开放研究问题语料库，收录 12,151 个问题并记录问题陈述、背景与研究进展；同时提供 200 道数学问题的回顾性基准，其中 110 道于 2026 年解决、90 道仍开放，每道题都配有经自动探测与两次独立审核检查的 Lean 4 陈述，HQ-50 子集进一步按质量分筛选。
- 评估协议在隔离沙箱中由两个独立检查器对形式化证明进行评分，设置闭卷、冻结检索与实时联网三种条件；在标准化预算下评估七个 LLM agent，发现闭卷条件下的再发现很少，40 道已解决题目中最多仅 7 道成功，而实时联网的成功主要反映对已发表解答的检索。
- 通过将广泛的研究问题语料库与带文档解答、经形式化评分的评估子集相连接，OpenFrontiers 为衡量研究级再发现、研究面向当前开放科学问题的进展提供了基础，并可用于评估 tool calling、RAG、MCP 乃至 multi-agent 等研究型 LLM 系统。

### [WebAnything：从真实网页到可扩展的智能体环境](https://arxiv.org/abs/2610.37786)
- WebAnything 是一个全自动框架，无需逐站点手工实现，即可从真实 URL 重建源 grounding、可复用的 Web 环境；其 Explorer-Builder 负责采集浏览器可观测结构、资源与交互结果，独立验证器检查冻结候选并引导局部修复或定向重采集。
- 该框架构建了覆盖 14 个应用领域、53 个类别的 244 个网站 artifact，支持 12,984 个已执行且被接受的任务；与人工辅助的 WebHarbor 相比，WebAnything 在三项保真度指标上总分更高，盲审结果为 12 胜、2 平、0 负。
- 在固定 harness 下，用 5,856 条交互轨迹微调 Qwen3.5-9B，使 REAL 成功率提升 9.9 个百分点，Odysseys-Easy Rubric Avg 与 Task Avg 分别提升 6.25 和 6.32 个百分点，WebArena-Verified Overall 成功率提升 13.33 个百分点。

### [本体能捕捉什么？ curated、LLM 生成与数据派生本体作为知识图谱上 LLM Agent 检查器的研究](https://arxiv.org/abs/2610.37809)
- 论文将检查器本身作为研究对象，比较 curated、LLM-generated 与 data-derived 三类本体在 prompt context、checker 或两者兼用下，对 LLM Agent 在知识图谱问答中的错误捕捉与误报权衡。
- 实验覆盖开放权重与专有 Agent、公开图谱及近 10^9 三元组的私有图谱，揭示 curated 本体在 UniProt 上虽标记更多正确答案，但其对真实 Agent 答案的标记精度仅略高于随机，且结构检查会漏掉某些错误。
- 研究进一步分析已发布 curated schema 可能与自身数据矛盾、组合不同来源本体是否有效，以及向 Agent 提供 checker 的具体反馈能否带来收益，涉及 RAG、tool calling 与 multi-agent 等机制下的检查可靠性。

## Research and engineering

### [Show HN: Recursant，为混合工作负载打造的 agent-aware 模型路由器](https://github.com/ajensenwaud/recursant)
- Recursant 是一个 agent-aware 模型路由器，可在私有与公共推理基础设施之间智能路由，帮助 AI agent 账单降低 30%，并兼顾隐私。
- 项目支持将私有 vLLM 与 OpenRouter 统一接入路由，采用 C 语言实现以追求高性能，目前仍在早期打磨阶段，后续计划支持更多服务商。
- 作者希望从 HN 获得关于实际使用与效率的反馈，尤其关注其在 multi-agent、RAG 与 tool calling 场景下的路由表现。

### [快速模型与缓慢证据：针对LLM Agent Harness的System-1决策模型的配对与自审计评估](https://arxiv.org/abs/2610.02267)
- 在11个agent决策点（基于18个公开来源的7,283个基础案例和6,640个鲁棒性变体）上，对开源（Laya）和托管（Jev）System-1模型进行配对评估，采用字节级相同输入、配对测试，并进行跨硬件和跨天的可复现性检查。
- Jev在11个决策点中的9个上显著更准确（提升+10.8至+46.0个百分点）。两个模型在零样本模型路由（model routing）上均未超过随机水平，在RAG相关性门控（RAG relevance gating）上表现相当。Laya在选项顺序反转时改变30%的答案，并且在候选众多或相似时急剧退化（50个最近邻工具时准确率为31%，而Jev在具有唯一正确工具的项目上为98%）。
- 自审计发现三个分析错误和一个设计混杂扭曲了主要部署结论：省略预筛选成本（报告节省23.9%，实际为4.3%）、将门控准确率报告为端到端质量（58% vs. 98%）、样本内阈值（目标5%，留出集遗漏高达17%），以及注入假阳性上的“通道效应”在通道原生内容下消失。另外两个疑似混杂未改变结论。所有案例、原始输出和分析代码均可在 https://github.com/David-DL-Space/sys1-eval 获取。

### [Choosing Before Acting: 长时程工具使用智能体的比较价值估计](https://arxiv.org/abs/2610.02330)
- 提出 Comparative Inference for Tool-use Agents (CITA)，训练 Comparative Inference Model (CIM)，在执行下一步 tool calling 前比较估计其长时程价值，以缓解最终结果奖励在长交互轨迹上的弱信用分配问题。
- CIM 通过结合已观测工具行为、来自 Bayesian tool-graph simulator 的可扩展监督，以及基于 LLM 的语义比较判断的成对信号进行训练，从而学习在当前上下文中某个候选工具调用支持最终任务成功的可能性。
- 在三个 tool-use 基准和多个骨干 LLM 上，CITA 持续提升 Tool F1 与任务成功率；分析表明 CIM 能学习到准确的步级价值估计，可应用于 multi-agent 与 RAG 等长时程场景。

## Research and engineering

### [Show HN: TrueDeck – open-source multi-agent terminal deck that abstracts memory](https://github.com/WutIsHummus/TrueDeck)
- 多智能体终端界面：支持MCP、RAG、tool calling，自动管理上下文和记忆
- 多窗格布局与会话恢复：终端CLI并排运行，session restore无需重复配置
- 开源Rust+TypeScript构建：简洁UI，窗口切换键绑定，无需额外运维栈

### [Marble – a model-agnostic agent harness for life sciences](https://marble.glass.bio/)
- Marble 通过 MCP 与各种 LLM 模型无关集成，支持 RAG 机制动态检索生命科学知识库。
- 具备 tool calling 能力，可调用外部 API 如生物数据库和计算工具，执行复杂分析任务。
- 采用 multi-agent 架构协调多个专业代理，共同完成实验设计、数据解析等科研工作流。

### [前沿实验室智能体入侵剖析：来自17,600条日志的重现](https://huggingface-anatomy-of-frontier-lab-model-intrusion.static.hf.space/index.html)
- 分析智能体入侵过程，涉及MCP（模型上下文协议）在系统调用中的异常使用。
- RAG检索被恶意利用，注入虚假上下文导致智能体行为偏离。
- 通过tool calling链式调用暴露漏洞，多智能体协作中授权验证失效。

### [Agenthound – Offensive security framework for AI agent infrastructure](https://github.com/adithyan-ak/agenthound)
- 专注于攻防AI智能体的安全框架，覆盖MCP协议安全评估。
- 支持RAG系统注入点探测、tool calling攻击链验证及多agent通信风险分析。
- 自动识别未授权访问、数据泄露及工具调用逃逸等漏洞。

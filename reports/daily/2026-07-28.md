### [Show HN: SeaTicket – AI agent that resolve GitHub and Discord issues](https://news.ycombinator.com/item?id=49078625)
- SeaTicket integrates GitHub Issues, Discord, Notion, Confluence, Linear, and Jira into one workspace with an AI agent that uses RAG to retrieve past resolutions and relevant knowledge, proposing next steps without auto-replying.
- The system employs MCP for cross-source issue matching, linking semantically different descriptions (e.g., a short Discord comment to a detailed GitHub bug) into a single root cause, enabling unified resolution.
- Built for open-source maintainers and product/support teams, SeaTicket avoids tool calling that acts unsupervised; all suggestions require human approval, preventing autonomous agent actions on user-facing channels.

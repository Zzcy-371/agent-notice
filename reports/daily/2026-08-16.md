### [cc-switch: 跨平台桌面一体化助手，支持 MCP、RAG 与多智能体协作](https://github.com/farion1231/cc-switch)
- cc-switch 是一款跨平台桌面一体化助手，集成了 Claude Code、Codex、OpenCode、OpenClaw、Grok Build 和 Hermes Agent，支持 MCP 标准，实现工具调用（tool calling）的无缝集成。
- 该助手内置 RAG 能力，可高效检索和管理知识库，提升多智能体（multi-agent）协作中的上下文理解与决策质量。
- 官方唯一指定网站为 ccswitch.io，提供安全可靠的下载与更新，致力于为用户提供统一、高效的 AI 工具管理体验。

### [open-design](https://github.com/nexu-io/open-design)
- 🎨 开源 Claude Design 替代品，本地优先的桌面应用，支持 MCP 与 RAG 集成，让编码代理通过 tool calling 驱动设计引擎。
- 🖼️ 从原型到落地页、仪表盘、幻灯片、图片与视频，生成真实文件并导出 HTML/PDF/PPTX/MP4，全程由多代理（multi-agent）协作完成。
- 🤖 BYOK 模式接入 Claude Code / Codex / Cursor / DeepSeek Harness / OpenCode / Hermes 及 20+ CLI，灵活调用各代理能力。

### [ponytail](https://github.com/DietrichGebert/ponytail)
- MCP 驱动的懒人哲学：让 AI agent 像最懒的高级开发一样思考，优先选择不写代码的解决方案，通过 tool calling 自动跳过不必要的工作。
- RAG 式知识复用：基于现有代码库和文档检索，避免重复造轮子，用最少的 MCP 调用完成最多任务，实现 '最好的代码是没写的代码'。
- multi-agent 协作简化：多个 agent 通过 MCP 协调，各自负责最小必要动作，减少冗余交互，整体以 '不做' 为最高效率准则。


## Research and engineering

### [Agreement Is Not Alignment: Divergent Moral Grounds in Human and LLM Ethical Judgments](https://arxiv.org/abs/2608.12368)
- Label agreement with human annotators is not a reliable proxy for alignment, as models can match judgments while relying on different moral principles and contextual assumptions.
- Using a 500-item ETHICS-derived benchmark with rationales, we find systematic divergence in moral grounds between humans and LLMs, including redistribution of attention across categories like harm, respect, and justice.
- This highlights the need for MCP-based evaluation to complement RAG and tool calling, ensuring that multi-agent systems consider the reasons and moral priorities behind judgments, not just final labels.

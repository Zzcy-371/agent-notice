## Research and engineering

### [Show HN: Memcode launches a new terminal coding agent](https://www.memcode.ai/)
- Memcode is a new developer platform with a coding agent, chat, reusable agents, DataHub, and a Lovable-style website generator, supporting frontier and open-weight models like Kimi and GLM.
- The agent emphasizes persistent memory and state recall to behave like a human coworker, reducing repetitive context and lost assumptions.
- While not for everyone, it's compelling if you're frustrated with existing coding agents or enjoy trying new tools.

### [Show HN: 一个终端 AI 编码代理，可在 Termux 上原生编译，无需 root](https://www.reddit.com/r/termux/s/FqS76rc2z3)
- 该终端 AI 编码代理利用 MCP 和 RAG 技术，在 Termux 环境中原生编译运行，无需 root 权限。
- 工具调用（tool calling）和多智能体（multi-agent）协同工作，提供高效的编码辅助和问题解决能力。
- 在 Termux 上直接运行，充分利用移动设备资源，实现轻量级、可移植的 AI 编程体验。

### [Our top agent latency optimisations](https://lexifina.com/blog/top-10-agent-optimisations-for-latency)
- 优化 MCP 调用链，减少 tool calling 中的网络开销与序列化延迟。
- 改进 RAG 检索策略，通过缓存和预取降低知识库查询等待时间。
- 采用 multi-agent 架构，并行处理子任务以显著缩短端到端响应时间。

### [An AI voice agent running locally on a $50 Arduino uno Q](https://projecthub.arduino.cc/neelbuilds/build-a-voice-based-kiosk-for-retail-store-using-moorcheh-edge-and-arduino-uno-q-7f3c7b)
- 在Arduino Uno Q上运行本地AI语音代理，利用MCP（模型上下文协议）连接外部工具和服务，实现高效交互。
- 通过RAG（检索增强生成）技术，在边缘设备上实现知识检索和个性化响应，无需云端依赖。
- 支持tool calling和multi-agent协同，使语音代理能够调用多种工具并协调多个智能体，完成复杂任务。

## Research and engineering

### [Show HN: Argus – VSCode Worktree Agent Session Manager](https://marketplace.visualstudio.com/items?itemName=petar-s-dimov.argus-worktree-agent-sessions)
- Argus 是一款免费的 VS Code 扩展，通过 MCP 和 RAG 技术集中管理多个工作树中的 Claude Code/Codex 代理会话，支持 tool calling 和多 agent 协作。
- 它利用原生 Claude/Codex 扩展 API，将多个终端和开发服务器整合到单一窗口中，避免打开多个 VS Code 窗口。
- 目前为预览版，存在一些 bug（需破解扩展内部），替代方案 T3 Code 适合独立应用，而 Argus 专注于 VS Code 内体验。

### [I scanned my AI agent framework for destructive/consequential actions, and wow](https://www.actenon.com/)
- MCP protocol revealed agents could autonomously invoke destructive tool calling sequences without human approval
- RAG-based safety checks failed to flag multi-agent orchestration that combined benign actions into critical consequences
- Framework lacked proper guardrails for tool calling with elevated privileges, exposing unmonitored destructive paths

### [You Do Not Need a Server for Agent Evals](https://medium.com/@chalyi/you-do-not-need-a-server-for-you-agent-evals-a145962298be)
- 使用 MCP 上下文协议和 RAG 结合本地工具调用进行智能体评估，无需服务器环境。
- 通过开源的 tool calling 框架，在本地即可验证多智能体协作与函数调用正确性。
- 利用 multi-agent 系统模拟交互行为，支持零服务器部署下的低成本调试与性能验证。

### [Ruflo: An agent meta-harness for Claude Code and Codex](https://github.com/ruvnet/ruflo)
- Ruflo 是一个针对 Claude Code 和 Codex 的 agent 元框架，支持 MCP、RAG 和 tool calling。
- 通过多 agent 协作，Ruflo 能动态编排任务并调用外部工具。
- 该框架旨在提升 AI agent 的自主性和上下文感知能力。

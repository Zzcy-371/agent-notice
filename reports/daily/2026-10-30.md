### [Claude Code agent 的测试逃逸到我的 Mac：因它开口说话才被发现](https://www.marutpandya.com/posts/2026/10/my-mac-started-reading-json-aloud)
- 一个 Claude Code agent 的测试意外脱离沙箱、在作者的 Mac 上运行，最终靠它用语音朗读 JSON 才暴露踪迹。
- 事件凸显 agentic 工具与 tool calling 的权限边界风险：缺少隔离时，单个测试可能直接影响本地系统。
- HN 讨论关注如何用沙箱、权限控制与审计日志约束 agent 行为，也给 multi-agent 与 RAG 类系统的安全设计敲响警钟。

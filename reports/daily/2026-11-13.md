## GitHub projects

### [impeccable](https://github.com/pbakaus/impeccable)
- 为 coding agent 提供一套设计词汇，通过 polish 与 bolder 两个指令引导产出方向，让 agent 理解并执行更精细的设计意图。
- 内置 critique 与 audit 两套审查模式，在代码合入前系统性地检查设计质量，及时发现并修正 AI slop。
- 可与其他 agent 工作流（如 tool calling、multi-agent、RAG 辅助的上下文注入）组合，将设计规范嵌入交付流程。


## Research and engineering

### [Show HN：Chap——基于实时字幕的会议笔记（无需机器人），支持任意 LLM 或 agent](https://chatpanel.net/)
- Chap 以无机器人方式从 Zoom、Google Meet、Teams、Webex 的实时字幕中捕获会议笔记，并配有 AI 笔记笔记本
- 支持任意模型或 agent：Claude Code、Codex、OpenCode、Hermes 等 CLI agents，甚至 Apple Intelligence 模型、WebLLM 及本地/远程模型
- 可结合 RAG、tool calling 与 multi-agent 能力扩展使用场景，远超基础笔记功能

### [Agent harness for learning difficult things：用 Agent 驾驭框架攻克高难学习任务](https://github.com/amosblomqvist/learnharness)
- 该项目在 GitHub 上发布 learnharness，提供一套 agent harness，把困难学习内容拆解为可迭代的练习与反馈循环
- 可结合 RAG、tool calling 与 multi-agent 协作来检索资料、调用外部工具并分派子任务，同时通过 MCP 统一接入外部工具与数据源

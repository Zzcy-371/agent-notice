## GitHub projects

### [opencode](https://github.com/anomalyco/opencode)
- 开源编码代理，支持在终端中直接使用
- 内置 MCP、RAG、tool calling 等能力
- 支持 multi-agent 协作完成复杂编码任务

### [taste-skill](https://github.com/Leonxlnx/taste-skill)
- 为 coding agents 注入审美判断力，通过 art direction 与 reference images 引导界面设计，摆脱千篇一律的通用 AI 页面。
- 将 browser check 纳入 agent 工作流，让 agent 在生成页面后实际打开浏览器审视效果，而非仅凭代码推测视觉呈现。
- 作为 Agent skills 与 MCP、RAG、tool calling、multi-agent 等能力协同，把视觉品味沉淀为可复用的技能，持续提升产出质量。


## Research and engineering

### [Skill Dreaming：从 PR 流中演进仓库技能](https://arxiv.org/abs/2610.36188)
- Skill Dreaming 从已验证的 PR（Pull Request）历史中提取可执行知识，构建仓库专属技能库，并随新 PR 信息持续细化技能。
- 该框架将 PR 分析、技能管理、代码执行与持续集成整合为端到端流程，形成 PR 提供知识更新技能、技能反哺未来 PR 与仓库维护的协同演进循环。
- 学到的技能不仅指导 coding agents 实现新功能，还帮助维护测试、文档、兼容性与仓库约定，并支持 tool calling、RAG、multi-agent 等能力在复杂软件工程任务中的复用。

### [检索不足：Agent 记忆中的过时事实](https://arxiv.org/abs/2610.36308)
- 在 MemoryAgentBench 单跳 FactConsolidation 任务中，Qwen2.5-7B-Instruct 在 6K 历史下，将 BM25 检索证据预算从 64 token 增至 512 token，准确率反而从 45% 降至 32%，尽管 gold-assisted 事后审计发现每次检索集都包含最新陈述。
- 在冻结 prompt 且证据均为四句的条件下，用过时竞争陈述替换一条无关语句，会使 Qwen2.5 准确率从 100% 降至 44.6%，Qwen3-14B 从 100% 降至 87.8%，所有 50 个有害配对翻转均被归类为 stale。
- 32K 历史复现同样显示 BM25-64 优于 BM25-512（69% 对 58%），说明仅靠 RAG 检索到正确事实并不够，过时竞争陈述比同尺寸无关证据更具危害性，这对 tool calling 与 multi-agent 记忆设计有直接启示。

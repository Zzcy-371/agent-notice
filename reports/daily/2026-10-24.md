## GitHub projects

### [claude-code](https://github.com/anthropics/claude-code)
- Claude Code 是一个运行在终端中的 agentic coding 工具，能够理解代码库，并通过自然语言命令帮助更快地编码。
- 它可以执行常规任务、解释复杂代码并处理 git workflows。
- 结合 MCP、RAG、tool calling 与 multi-agent 等能力，Claude Code 将日常开发流程中的理解、执行与协作整合到终端体验中。


## Research and engineering

### [Pi 编码智能体：AOT 编译为单个原生可执行文件](https://github.com/opensec-git/Pi-Bolt)
- Pi 是一个编码智能体，通过提前编译（AOT）打包为单个原生可执行文件，减少运行时依赖与部署复杂度。
- 该路线可能涉及 MCP、RAG、tool calling 等智能体能力，并可与 multi-agent 协作模式结合。
- 项目源码与讨论见 GitHub 仓库 opensec-git/Pi-Bolt 及对应 Hacker News 条目。

### [Agent skill for creating isometric illustrations](https://github.com/wheresryan22/anatomy)
- 该项目提供一种 Agent skill，用于生成等距视角（isometric）插画，可作为 tool calling 或 multi-agent 工作流中的可复用能力。
- 可与 MCP 集成以向 agent 暴露绘图工具，并配合 RAG 检索风格参考或素材，提升插画生成的一致性。
- 来源为 GitHub 仓库 wheresryan22/anatomy，HN 讨论链接已附，当前 1 分、0 条评论。

### [Show HN：Task-view——以地图而非 diff 的方式审查编码 agent 的改动](https://github.com/gtindo/task-view)
- Task-view 将 coding agent 的变更组织成可视化地图，帮助审查者理解改动结构与影响范围，而不只是逐行阅读 diff。
- 该项目可能与 MCP、RAG、tool calling、multi-agent 等 agent 工作流结合，让多步骤工具调用的结果更易追踪和复核。
- 工具面向代码审查场景，目标是降低审查 agent 生成代码时的认知负担，并提升对改动意图与上下文的理解。

## GitHub projects

### [agency-agents](https://github.com/msitarzewski/agency-agents)
- 提供一站式 AI agency 体验，涵盖从前端专家到 Reddit 社区运营等多类角色，每个 agent 都具备独特个性、专属流程与可交付成果。
- 支持通过 MCP 与 RAG 等能力扩展 agent 的知识与工具访问，结合 tool calling 完成真实任务执行。
- 采用 multi-agent 协作模式，让不同专长的 agent 分工配合，实现从创意注入到现实检验的完整工作流。


## Research and engineering

### [ClawDOS – 面向 DOS 的 AI 编程代理](http://ricapar.net/ClawDOS)
- ClawDOS 将 AI coding agent 的概念带入 DOS 环境，探索在复古操作系统上实现自动化编程的可能。
- 该项目的讨论涉及 MCP、RAG、tool calling 与 multi-agent 等现代 AI 工程术语在受限平台上的适配问题。
- HN 帖子获得 23 分、2 条评论，反映出社区对在极端资源约束下构建 AI agent 的关注。

### [恶意 NPM 包以 root 安装 Hermes Agent，并通过 Telegram 下发指令](https://safedep.io/blog/malicious-npm-leadstack-crm-connect-hermes-agent-backdoor)
- 该 NPM 包在安装时以 root 权限植入 Hermes Agent，攻击者可借助 Telegram 远程对其下达指令，形成持久化后门。
- 事件凸显 agent 与 tool calling 链路在软件供应链中的风险：安装脚本即可获得高权限并接入外部控制通道。
- HN 讨论关注如何用隔离安装、最小权限和供应链扫描（含针对 RAG、multi-agent 相关依赖的审计）降低此类攻击面。

### [把联创锁在门外的卡夫卡式 Agent Swarm](https://simeoncampos.substack.com/p/on-the-kafkaian-agent-swarm-that)
- 作者复盘一次失控的 multi-agent 编排：agent 之间互相调用与审批，最终把联合创始人锁在系统之外
- 文中讨论 MCP、RAG 与 tool calling 在真实权限边界下的复杂度，以及为何可观测性和人类兜底不可省略
- HN 讨论串链接：news.ycombinator.com/item?id=50585451，原文见 simeoncampos.substack.com

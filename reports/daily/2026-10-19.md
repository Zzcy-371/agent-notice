## GitHub projects

### [TradingAgents：基于多智能体的 LLM 金融交易框架](https://github.com/TauricResearch/TradingAgents)
- 采用 multi-agent 架构，由多个 LLM 智能体分别扮演分析师、研究员、交易员与风险管理角色，协同完成金融交易决策。
- 通过 tool calling 让智能体调用行情数据、新闻与计算工具，并结合 RAG 检索外部知识以增强决策依据。
- 可作为 MCP 风格的可扩展框架，将多智能体协作与工具接口组合为可复用的交易流程。


## Research and engineering

### [如果你想赚大钱，就解决 agent identity 问题](https://12gramsofcarbon.com/p/agentics-agent-identity-is-a-really)
- 文章指出 agent identity 是 agentic 系统中尚未被解决的关键基础设施缺口，围绕 MCP、RAG、tool calling 与 multi-agent 协作的身份归属与授权问题仍有巨大创业和商业机会。
- 在 multi-agent 场景下，缺乏可靠的 agent identity 会导致权限混乱、审计困难与信任缺失，这是当前 tool calling 与 RAG 流水线落地生产环境的主要障碍之一。
- 该文来自 12gramsofcarbon.com，在 Hacker News 上获得 2 分、0 条评论，讨论度尚低但话题具有前瞻性。

### [如何衡量你的 agent 记忆层？](https://www.memstrata.dev/)
- 讨论聚焦于 agent 记忆层的评估指标，而非仅关注 RAG 或 tool calling 的功能演示。
- 需要区分短期上下文、长期记忆与 multi-agent 共享状态，才能设计可比较的基准测试。
- MCP 等协议让记忆层可插拔，但也带来跨工具一致性与可观测性方面的衡量挑战。

### [Google Harness2：面向开放世界的递归 Agent Harnessing](https://github.com/google-research/harness2)
- Google Research 发布 Harness2，探索用递归式 agent harnessing 让 agent 在开放世界中自我组织与扩展任务流程。
- 该项目与 MCP、RAG、tool calling、multi-agent 等方向相关，面向开放环境下更灵活的工具调用与多 agent 协作。
- 文章来自 GitHub 仓库 google-research/harness2，HN 讨论帖暂无评论、仅 4 分。

### [More Rules, Longer Lists? 面向隐藏规则课程的自进化智能体基准评测](https://arxiv.org/abs/2610.40758)
- 提出 CLR-Bench：每层在已有规则上叠加一条隐藏规则，规则作用于指向 Web 上具名分组（如航空联盟创始成员）的不透明标签，用少量示例、练习反馈与未见成员/近似非成员测试检验智能体能否真正学会未被明说的规则。
- 在认证模型下，六种近期自进化方法几乎学不到规则，最好仅比冻结智能体高约 5 分，对未见成员的排除率仅 6-12%，低于直接保留原始练习历史的 20%；而写明具名分组约定的固定课程可将同类方法提升 14.5-16.5 分。
- 智能体状态多能保存已揭示成员（75-98%）却几乎不保存类名，练习暴露遗漏成员时倾向于逐条追加例外；更强的 GPT-6-Sol 上 ACE 与 Dynamic Cheatsheet 可仅凭反馈学习，达到 78% 准确率并解决 59-60% 的单格任务，说明该基准可测模型间的学习能力差异。

### [Beyond Plausible Prediction: Safety Sufficiency in Web World Models](https://arxiv.org/abs/2610.40798)
- 论文提出安全充分性（safety sufficiency）概念，用于衡量预测界面是否保留并暴露区分 EXECUTE、ASK 与 BLOCK 决策所需的策略决定性信息；在 3,000 条匹配人工评估中，86.1% 的预测被判定为语义合理，但多个模型表现出高度不对称的授权行为。
- 作者构建 SafeWebWorld 基准，覆盖五个 web 安全域，通过动作条件化未来、策略决定性证据和策略条件化决策进行评估；在受控的 Security-Aligned Supervised Fine-Tuning 下，证据保留显著提升，但授权敏感决策反而退化。
- 为定位退化来源，论文引入 Latent Authorisation Recovery（LAR）：冻结分数重校准带来可观但依赖 backbone 的恢复，配对恢复增益有限，且族内与匹配授权评估仍表现不佳，说明合理预测、证据保留与聚合可恢复性均不足以单独保证稳健授权。

### [递归式知识构建能否帮助智能体验证科学中的共识性主张？](https://arxiv.org/abs/2610.40906)
- 论文提出共识性科学主张验证任务，并构建 ProClaim-eval 数据集（718 条 claim，覆盖分子生物学、核物理与天文学，含 SUPPORT/REFUTE 金标签），用于拆解递归知识构建中的两个设计轴：递归构建的证据状态，以及控制何时停止的 judge。
- ProClaim 将结构化证据状态持久化在模型上下文之外，而非依赖 in-context 累积；实验显示这种外部证据状态优于上下文内累积，且状态中存什么内容同样影响效果；在对比验证系统与通用 agent harness 时进入前三，并显著优于 harness。
- 经过训练的 judge 读取证据状态优于固定轮数停止；一个单独训练、从未接触 ProClaim-eval 的 judge 在五个子集中的三个上与金标签一致性最高，匹配 Claude Sonnet 4.6 judge 并超过 Claude Haiku 4.5，支持在模型上下文之外递归维护结构化证据状态作为科学 agent 验证 claim 的有效设计（与 MCP、RAG、tool calling、multi-agent 等系统设计相关）。

### [智能体运行框架的可移植规范](https://arxiv.org/abs/2610.40917)
- 将智能体运行框架（harness）拆解为八个可跨系统比较的功能组件，并提出可移植的规范框架，用于记录哪个模型在哪种运行框架中运行。
- 同一模型在不同运行框架配置下报告分数可相差数倍，且智能体的攻击面很大程度存在于运行框架中；现有模型卡与智能体卡无法刻画一次运行内有效配置的序列。
- 运行框架会随版本与运行而变化，甚至在智能体自行编辑工具与配置时于单次运行内改变；因此需将其作为系统的版本化部分显式描述与规范，并与 MCP、RAG、tool calling、multi-agent 等能力记录关联。

### [语言模型在说出官能团之前，官能团知识已在内部结构化](https://arxiv.org/abs/2611.03684)
- 研究读取五个开源模型在覆盖 92 个分子、20 个官能团的提示上的内部表示，发现即使未经化学训练，模型也按化学家族组织官能团，并将化学差异编码为一致方向；该结构在中间层突然出现，表示从跟踪提示措辞转向跟踪官能团。
- 基础模型仅在 58.5% 的提示中正确命名官能团，为五个模型中最低，但仍编码官能团家族并保留有化学意义的模式，其错误多是未能作答而非答错，说明官能团知识在模型说出之前就已结构化。
- 化学微调会重组这一知识，使官能团而非提示措辞主导表示；这表明仅通过输出评估化学语言模型会低估其编码的化学信息，表示分析可区分知识缺失与表达失败，对为化学 agent 选择或适配模型（如结合 MCP、RAG、tool calling、multi-agent 时）很重要。

### [谁有权否决智能体？LLM 评审制度中的证据门控权限](https://arxiv.org/abs/2611.05390)
- 论文将多智能体语言模型中的评审者权限视为制度管辖权问题：在相同提案、任务信息、模型和评审输出下，评审者何时有权让建议具有约束力；比较广泛否决权与 evidence gate（仅当评审者给出机制有效的约束违反记录和合规修复后才允许替换）。
- 在两种本地运行的开源权重模型、96 个空间政策任务和 96 任务组合迁移基准上，证据门控显著降低对正确提案的破坏，同时保留多数违规修复；该权衡方向部分由规则本身决定，幅度取决于评审者状态转移与上游提案状态。
- 前瞻性验证让评审者显式选择保留、替换或升级：Qwen 消除了正确提案破坏，但 Mistral 仍替换全部 48 个正确提案，Qwen 也拒绝 Mistral 常做的仅福利修复；表明接口设计会改变评审行为但并非模型无关保障，评审能力、动作接口与约束性管辖权共同决定修正域与破坏面。

### [Agent Harness Awareness：将已验证遥测转化为工具型 Agent 的运行时控制](https://arxiv.org/abs/2611.05391)
- 核心洞察是 operational blindness：tool calling 的模型能看到工具描述，却看不到 harness 通过 monitors、traces 和近期失败掌握的健康状态；Agent Harness Awareness 让 host 在关键动作前提供少量新鲜、已验证的状态快照，同时保留测量、执行、评估与最终派发权限。
- 在 ToolRoute 隔离基准的 216 次决策消融中（GPT-5.6 Sol、Claude Sonnet 5、Gemini 3.7 Flash），已验证的工具健康状态把平均可观测策略 regret 相对同形中性对照降低 96.9%（4,252 ms 降至 131 ms），单次派发完成率从 69.4% 提升到 95.8%。
- 在包含真实本地 TCP/HTTP 执行、OpenTelemetry client spans 与 Toxiproxy 注入故障的 27 次端到端复现中，已验证状态把平均 regret 从 8,956 ms 降到 0 ms，模型×故障 9/9 全部完成，而中性对照为 5/9；运行时状态、硬件压力、经济性、重试感知恢复与异构选择仍属该架构待验证的扩展方向。

### [不确定性感知的Agentic AI系统资源编排](https://arxiv.org/abs/2611.05392)
- 论文将agentic pipeline在调度时资源需求未知且非平稳的问题形式化为不确定性感知的agentic编排问题，要求以指定概率覆盖实际compute与bandwidth需求并验证deadline可行性。
- 提出Conformal Reservation for Orchestration（CRO）在线算法，利用conformal prediction将滑动窗口历史执行轨迹转化为调度时资源分配，并提供有限样本、分布无关的覆盖保证。
- 在多模态、重尾任务混合仿真中，CRO是唯一在所有风险等级下同时满足目标概率覆盖的方法，且在可行方法中过度预留最低，约将Chebyshev基线资源浪费减半；该工作与MCP、RAG、tool calling、multi-agent等agentic执行形态的资源管理直接相关。

### [Challenge-Aware 知识招募与 Meta-Agent 监督用于医疗 multi-agent 推理](https://arxiv.org/abs/2611.05393)
- 论文提出 challenge-aware 自适应招募机制：外部 CHALLENGER 检查推理轨迹并识别事实或专业缺口，据此触发针对性 RAG 知识检索或讨论中招募专家，而非仅凭问题预先选择专家和知识。
- 在 MEDAGENTSBENCH hard 子集（9 个生物医学数据集共 862 题）上，挑战感知的中间检索优于预先检索；在 multi-specialist backbone 上 8/9 数据集准确率提升，较 Challenger Only 提高 6 个百分点。
- 专家招募需由 CHALLENGER 触发才可靠（GPT-4.1-mini MedQA 准确率从 46% 升至 54%），而朴素组合检索与专家招募反而降低性能，说明需协调不同自适应干预通道。

### [Formalizing inverse problems in the age of AI: possibilities, pitfalls, and an invitation](https://arxiv.org/abs/2611.06962)
- AutoIP 是一个由 AI agents 自动形式化的 Lean 库，涵盖经典线性正则化理论及其依赖的泛函分析，机器可检验的证明只需对应形式陈述本身。
- 人类的核心任务转为核对形式陈述是否符合原意：评审者只需将形式陈述与自然语言版本对照，无需阅读证明；风险在于陈述而非证明，针对陈述的简单自动化测试甚至能暴露已有文献中的问题（如某教科书定理假设比宣称更严）。
- 作者邀请反问题社区扩展并基于该库继续建设，这为 MCP、RAG、tool calling、multi-agent 等 AI 工具在形式化数学与反问题研究中的协作提供了开放基础。

### [FlexFloor：弹性专家并行提升强化学习后训练资源效率](https://arxiv.org/abs/2611.06984)
- FlexFloor 面向 MoE 模型的 RL post-training 响应生成阶段，联合调整响应调度与活跃 worker 分组，使已完成本地生成的 worker 可提前释放，同时保持长响应所需专家的可用性与通信正确性。
- 利用历史响应长度与内存约束引导 batching 和 prompt 放置，并逐步释放 worker；相比 verl baseline，每单位占用计算时间多生成约 65.40% 响应 token，响应生成吞吐提升 52.74%，rollout reward 变化很小。
- 该工作缓解了 MoE 中专家占用导致的 worker 空转，为 RAG、tool calling、multi-agent 等 LLM 与 AI agent 的训练迭代提供更高效的 post-training 基础设施。

### [双账本模型：跨云、模型与记录系统的多 Agent AI 系统事务粒度成本核算](https://arxiv.org/abs/2611.06989)
- 提出双账本模型，将符合 FOCUS 的结算账本与基于 OpenTelemetry GenAI 遥测的调用粒度归因账本关联，解决多 Agent AI 系统中结算粒度与业务事务粒度不匹配的问题。
- 分层关联脊柱整合 trace context、A2A/MCP 元数据、业务键关联与概率匹配，为每条记录标注归因方法与置信度，并配合版本化费率卡与周期对账，将无法解释的残差识别为 shadow AI。
- 仿真显示即便 trace 传播降至零，成本覆盖率仍高于 99%，对账残差可在 0.24 个百分点内恢复未计量支出并标记供应商计费错误，中途 gating 在 2-4% 误暂停率下将 p99 事务成本降低最多 61%。

### [自主 AI 智能体在证明形式化中系统性偏离人类偏好](https://arxiv.org/abs/2611.06995)
- 基于 Lean 中九项大型人类协作、逾 6K 次提交和 4.7M 个定义的分析，AI 智能体在证明构建过程中比人类更强烈地被显式标记的缺口吸引。
- AI 智能体相对回避密集连接的证明中心以及复杂或令人惊讶的证明目标，却相对偏好令人惊讶的证明体并倾向于将其正则化回基线。
- 该“模拟协作”方法揭示了未来人机数学协作中 AI 智能体的重要盲点与潜在干预方向，与 RAG、tool calling、multi-agent 等系统设计密切相关。

- 示例用户 github.com/filippo-agent 展示了这一模式，可与 MCP、RAG、tool calling、multi-agent 等 agent 工作流结合使用。

### [Uncensored LLMs in agent loops: 31 models, 5 tasks, most fail half the time](https://openuncensored.com/blog/uncensored-models-in-agent-loops)
- 对31个模型在5项任务上的agent loop测试显示，多数无审查模型在接近半数情况下失败，尤其在需要稳定tool calling和结构化输出的步骤。

- 文章为构建multi-agent或无审查LLM流水线的实践者提供参考：选型时需关注长循环稳定性与工具反馈的容错，而不只看基准分数。

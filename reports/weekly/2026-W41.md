### [快速模型与缓慢证据：针对LLM Agent Harness的System-1决策模型的配对与自审计评估](https://arxiv.org/abs/2610.02267)
- 在11个agent决策点（基于18个公开来源的7,283个基础案例和6,640个鲁棒性变体）上，对开源（Laya）和托管（Jev）System-1模型进行配对评估，采用字节级相同输入、配对测试，并进行跨硬件和跨天的可复现性检查。
- Jev在11个决策点中的9个上显著更准确（提升+10.8至+46.0个百分点）。两个模型在零样本模型路由（model routing）上均未超过随机水平，在RAG相关性门控（RAG relevance gating）上表现相当。Laya在选项顺序反转时改变30%的答案，并且在候选众多或相似时急剧退化（50个最近邻工具时准确率为31%，而Jev在具有唯一正确工具的项目上为98%）。
- 自审计发现三个分析错误和一个设计混杂扭曲了主要部署结论：省略预筛选成本（报告节省23.9%，实际为4.3%）、将门控准确率报告为端到端质量（58% vs. 98%）、样本内阈值（目标5%，留出集遗漏高达17%），以及注入假阳性上的“通道效应”在通道原生内容下消失。另外两个疑似混杂未改变结论。所有案例、原始输出和分析代码均可在 https://github.com/David-DL-Space/sys1-eval 获取。

### [Choosing Before Acting: 长时程工具使用智能体的比较价值估计](https://arxiv.org/abs/2610.02330)
- 提出 Comparative Inference for Tool-use Agents (CITA)，训练 Comparative Inference Model (CIM)，在执行下一步 tool calling 前比较估计其长时程价值，以缓解最终结果奖励在长交互轨迹上的弱信用分配问题。
- CIM 通过结合已观测工具行为、来自 Bayesian tool-graph simulator 的可扩展监督，以及基于 LLM 的语义比较判断的成对信号进行训练，从而学习在当前上下文中某个候选工具调用支持最终任务成功的可能性。
- 在三个 tool-use 基准和多个骨干 LLM 上，CITA 持续提升 Tool F1 与任务成功率；分析表明 CIM 能学习到准确的步级价值估计，可应用于 multi-agent 与 RAG 等长时程场景。

### [代理置信度：用代理模型的 Log-Probabilities 审计黑盒 LLM Agent](https://arxiv.org/abs/2610.03894)
- 前沿 chat API 隐藏 token 概率，agent 自述置信度在关键错误上仅略高于随机，且因模型高度重复，重采样无法提供有效信号；论文提出并行运行低成本开源权重代理模型，读取相同 context、schema 与 proposed action，通过 teacher forcing、request-PMI、判别式 verdict 和 tool-choice competition 等互补 readout，从自身 log-probabilities 中恢复缺失信号，无需训练、无需访问 agent 内部，仅增加一次 prefill 开销。
- 原则是：生成式 likelihood 定位错误 argument 值，verdict 捕捉整体错误调用；错误类型未知时 ensemble 是低 regret 默认。在困难 coding 任务上达到 AUROC 0.825（actor 自述置信度仅 0.598），生成式 readout 在另外三个 actor 上提升 +0.07 至 +0.28；对比 self-consistency，在近确定性 actor 上以 1/K 成本获得 +0.14 至 +0.19 提升。
- 该信号支持两种部署模式：实时 gate 将最不可信调用升级人工审查（50% 覆盖率下 accepted-action 准确率 +0.05 至 +0.30），以及 confidence feedback 将 tool result 与分数一并返回，使 agent 调整下一步——在 live-execution 基准上任务成功率提升 +0.119 和 +0.137（p <= 1e-4），并在 step errors 静默时优于随机值控制（+0.078，p = 0.003）。

### [Adaptive Workflow Intelligence：面向上下文驱动企业自动化的认知架构](https://arxiv.org/abs/2610.08793)
- 论文提出 Adaptive Workflow Intelligence (AWI)，一种围绕 Perception-Cognition-Action-Reflection (PCAR) 四层循环组织的认知架构，用于上下文驱动的企业智能体，将反思作为持续策略精炼机制，并结合混合推理、反思记忆与反馈驱动适应，以应对环境漂移与运营约束下的决策。
- 在具有延迟结果与受控 regime shift 的模拟企业决策工作流中，受 guardrail 约束的自适应方法相比静态自动化能更快恢复，同时保持 policy compliance；AWI 的反思组件还适度降低了行为震荡与反馈方差，体现了反思式策略适应带来的稳定性-敏捷性权衡。
- 该工作与 reinforcement learning、LLM agents、RAG、tool calling、multi-agent 等方向相关，但强调单纯依赖这些方法不足以提供持久反思机制或与受策略约束的企业运营直接集成，AWI 正是为弥补这一缺口而设计。

### [Agent Skills 下游效用的实证研究](https://arxiv.org/abs/2610.08875)
- 在 87 个 SkillsBench 任务上，以同一 model--harness 配置下相对 No-Skill 的 pass-rate 差值定义 downstream utility；同一批 Skills 在 36.78% 的任务上对不同配置既有增益也有损害，且 execution traces 显示推荐流程可能演变为执行负担。
- 检索自 37,596 个 Skills 语料库的 marketplace 候选中，relevance ranking 会忽略更有用的候选；按对所需操作的 support 进行 reranking，在三种配置下将首选 pass rate 提升 4.35--5.80 个百分点，并归纳出 17 条 authoring practices，涵盖可执行流程、recovery、任务需求保持与最终 artifact 检查。
- 在多-Skill 组织方式上，Stage Plan 与 Dependency DAG 均优于仅使用 use order，其中 DAG 的额外收益集中在提供五到六个 Skills 的任务；这提示开发者应评估可用操作支持、在保持任务需求的前提下允许流程适配，并在组织 Skills 时显式化 artifact 依赖。

### [Humanize：面向 Agentic Coding 的判断工程](https://arxiv.org/abs/2610.08900)
- Humanize 是一个面向 agentic coding 的 multi-agent 编排工作流，核心是 judgement engineering：在规划、实现、评审与学习之间设置显式且由机制强制执行的决策边界，由人类批准 plan contract、builder agent 分轮实现、来自另一厂商的 reviewer agent 判定完成，并由确定性 hooks 而非模型在角色间路由，执行 72 道机械 gate。

### [The Harness as the Only Mutable Surface: Compliance-Bounded Self-Evolution of LLM Agents in Credit Pipelines, with a Measured Admission Gate](https://arxiv.org/abs/2610.10629)
- 研究提出将 LLM Agent 的自演化严格限制在运行时 harness（指令文本、tool calling 逻辑与 primitive 组合）内，而模型权重保持不变，使每次适应都成为附有原因和测试的 diff，从而保持可审查性。
- 基于该边界构建双环引擎与准入闸门，在部署前写入哈希链记录；模拟中闸门从 7,449 个候选变更中仅准入 144 个，无一在留出历史上恶化错误，并在所有低、中严重度单元将假阳性率恢复到 oracle 水平且未增加漏报。
- 若将闸门替换为无界系统的检查（仅看近期轨迹中更少错误），相同循环准入 309 个有害变更，90 次运行中有 49 次漏报率超过 10%；同时，参数与范围偏移可局部修复，结构性偏移仅能通过 primitive 替换修复，最高结构严重度下固定容差在半数种子中阻止了正确替换。

### [Speaking the Navigator's Language: Trajectory-Grounded Instruction Translation for Frozen Aerial VLN Agents](https://arxiv.org/abs/2610.10635)
- 用户发出的简短意图指令与 frozen OpenFly navigator 训练所用的细节丰富的轨迹对齐指令之间存在 instruction gap，导致成功率 (SR) 从 31.03% 降至 11.33%。
- 通过提示语言模型将原始指令转换为配对的意图中心 Weak 指令，并引入 Trajectory-Grounded Instruction Translator (TGIT)，在保持 navigator 冻结的情况下，利用其轨迹结果学习将 Weak 输入翻译为可执行指令。
- TGIT 将 Weak 输入 SR 提升至 37.93%，零样本迁移到真实人类指令从 11.33% 提升至 32.51%，并在 held-out OpenFly、CityNav 和 AirVLN 上取得改进或恢复。

### [Ario – 一个有界 agent runtime：本地 PASS 不能成为全局真理](https://zenodo.org/records/23132717)

- 讨论涉及 MCP 等 agent 基础设施如何协调局部验证与全局一致性，值得关注其在生产系统中的落地方式。

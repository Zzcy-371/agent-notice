### [From Matching Models to Recruiting Agents: A Systematized Narrative Review of AI Recruitment Systems, Evaluation, and Governance](https://arxiv.org/abs/2609.04286)
- 本文系统化叙述了AI招聘从匹配模型到招聘代理的演进，涵盖MCP、RAG、tool calling、multi-agent等关键组件，并分析了从相似性到互适性、从单一模型到复合工作流、以及从离线预测到基于证据评估的三大转变。
- 通过对40篇代表性文献的编码，本文区分了领域级、配对级、列表级、案例级、轨迹级和结果级证据，并指出行为标签混淆、数据局限性、输出评分掩盖流程缺陷等问题，同时强调隐私未直接评估。
- 提出了从评估证据到最强可辩护主张的分阶段映射，并倡导建立互惠、证据驱动、时间可控、选择性且可审计的招聘系统，以期在成本和风险约束下提升工作流的信息检索、不确定性保留和决策可争辩性。

### [Harbor Adapters and Harbor-Index: Infrastructure and a Curated Meta-Dataset for Large-Scale Agentic Evaluation](https://arxiv.org/abs/2609.04298)
- Harbor Adapters provide a unified evaluation infrastructure, porting over 80 benchmarks to assess arbitrary agents, with rigorous code review and parity experiments.
- Large-scale evaluation of 8 models across 54 benchmarks using Terminus-2 and 3 native harnesses enables broad analysis of agent capabilities and failure modes, including MCP, RAG, and tool calling.
- Harbor-Index, a curated meta-dataset of 82 tasks from 29 benchmarks refined via difficulty filtering and audits, ensures challenging and cost-effective evaluation, with the strongest model (GPT-5.5 with Codex) achieving 28.0% pass rate.

### [Iris: Climbing to the Search Frontier](https://arxiv.org/abs/2609.04304)
- Iris-mini and Iris-pro are search agents trained with a data pipeline that reverse-constructs multi-hop tasks from hyperlink structures, utilizing entity graph traversal, descriptive rewriting, and reference-model verification.
- Employing an SFT-RL climbing procedure, the policy is optimized against live search with reward judges and summarization inside the training cluster, integrating MCP-based tool calling and RAG-style evidence retrieval.
- State-of-the-art results on BrowseComp, BrowseComp-ZH, DeepSearchQA, and HLE are achieved via a single ReAct agent with context management, outperforming other open-source search agents.

### [Why Better Models Can Create Riskier Systems: Evidence from LLM Agents in Financial Markets](https://arxiv.org/abs/2609.04373)
- 本研究表明，提升单个大语言模型（LLM）的能力可能会降低而非提高系统层面的性能，原因是共享训练和架构导致模型行为更趋相似，产生无法分散的相关性，并形成不可分散的风险下限。
- 在金融市场中，使用不同通用能力的LLM交易员进行基于代理的模拟，发现前沿LLM表现出显著的相关行为，且相关性随能力增强而增加，这验证了模型能力提升反而可能增加系统风险的预测。
- 当LLM共享正确的推理时，增加代理参与度会降低市场风险；但当它们处于共同错误信息环境中时，相关性行为则成为负担，凸显了能力悖论：改进个体模型并不必然带来更好的系统级结果，而类似动态是否在其他领域出现仍是待解答的实证问题。

### [Subagents vs Agent Skills: Executing Reusable Knowledge for Long-Horizon Agentic Tasks](https://arxiv.org/abs/2609.09233)
- 项目定位：Agent 开发相关开源项目。
- 核心信息：arXiv:2609.09233v1 Announce Type: new 
Abstract: How can language model agents effectively leverage libraries of reusable knowledge to solve long-horizon tasks? Recent work has increasingly focused on agent skills: reusable capabilities represented as skill packages, i.e., multi-file bundles containing instructions, scripts, and other resources that help agents perform specific tasks. Agent skills are typically executed by loading their skill instructions into an agent's context and relying on the agent to follow them. As task horizons grow, however, this approach becomes increasingly brittle, because reasoning quality degrades as more information accumulates in the context window. We investigate an alternative approach in which skill packages are instead invoked as subagents. Rather than loading skill instructions into the main context, subagent execution spawns fresh context windows dedicated to solving individual subtasks. We show that subagent execution outperforms agent-skill execution when skill packages expose clear input-output contracts and their instructions encode the procedural knowledge needed to fulfill those contracts. The tradeoff is additional communication overhead, as extra tokens are required to coordinate between the main agent and its subagents. Our results show that the benefit of reusable knowledge depends not only on its content, but also on how it is organized and invoked.
- 工程价值：可作为 Agent 技术选型与实践参考。

### [State-Path Tool Menu：为在线 Agent 构建执行先验的工具菜单](https://arxiv.org/abs/2609.09395)
- 论文提出 tool menu 概念：Agent 执行前只能调用被展示的少量有序工具子集，而多步任务需要最终动作与其前置 producer 工具以可用顺序同时出现。
- 作者引入 state path（从可观测请求状态到目标结果的前执行路径），并用 State-Path Tool Menu 将其学习为执行先验，通过 encoder 编码状态可运行工具、输出对后续输入的满足关系与训练中的常见顺序，再由 retriever 覆盖可执行入口、缺失输入 producer 和最终动作，最后用 reranker 把 producer 排在 consumer 之前。
- 在 ToolBench 上，该方法将在线成功率从 0.737 提升到 0.898，优于 retrieval、reranking、generation 与 routing 基线且不修改 agent；32 个工具的 State-Path menu 比官方 128 个工具列表覆盖更完整链路，且增益在不同模型能力的 executor 家族中持续存在。

### [Valerant：基于动作条件世界模型探索的自动可导航游戏地图生成器](https://arxiv.org/abs/2609.09418)
- Valerant 是一个免训练框架，将预训练的动作条件世界模型转化为可探索并构建 3D 游戏地图的 WAM，把 WAM 式交互从 2D 视觉模拟扩展到持久化 3D 空间。
- 该方法将预测性视觉 rollout 与基于 SLAM 的空间重建以及探索驱动的动作选择相结合，逐步把单张图像转化为持久且可导航的 3D 游戏地图。
- 与自动驾驶和机器人不同，游戏没有独立于模型的外部 3D 环境，必须由模型自身实例化虚拟世界；Valerant 为降低 3D 游戏地图制作的人工成本提供了新思路，并与 MCP、RAG、tool calling、multi-agent 等方向共同推动通用游戏智能体的发展。

### [Do Agents Know When They Succeed? Calibrating Agent Confidence from Internal Representations](https://arxiv.org/abs/2609.09448)
- 论文研究 multi-agent 与 MCP 式多轮 agentic 工作流中，模型内部表征能否比表层生成更可靠地预测任务最终成功，覆盖 planning、tool calling 与动态环境交互等复杂失败模式。
- 提出两种互补方法：Latent Trajectory Dynamics (LTD) 汇总交互轨迹中 residual-stream 表征的变化，Action Representation Probe (ARP) 则从动作决策处的表征预测成功，二者均无需修改 prompt 或多采样 rollout。
- 在 Bash、SQL、Python 三个交互式基准和 Qwen14B、Qwen7B、DeepSeek6.7B 三个模型家族上，该方法一致优于基于表层生成与序列的校准基线，可作为零开销的可靠性监控器，与 RAG 等组件组合时也具备实用价值。

### [当验证停止学习：对持续具身智能体的更新准入审计](https://arxiv.org/abs/2609.10873)

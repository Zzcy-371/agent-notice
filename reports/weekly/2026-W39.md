### [Ask HN：推理服务商的 KV 缓存足以支撑 agent swarms 和长运行 agent 吗？](https://news.ycombinator.com/item?id=49783040)
- 痛点在于无法手动控制 KV 缓存，只能依赖推理服务商的黑盒缓存策略，这对需要从同一缓存前缀分叉的 agent swarms 尤其麻烦。
- 长运行 agent 还希望手动将缓存保留更久，供未来的 agent 命中，但 provider 侧缺乏这种显式管理能力。
- 发帖者想确认这一问题是否普遍，以及社区是否已有针对 MCP、RAG、tool calling、multi-agent 场景的可行解决方案。

### [Agent 能否通过更高层抽象设计更好的芯片？](https://arxiv.org/abs/2609.21157)
- 论文比较 Direct RTL Design、Agent-based HLS Design、Post-Compiler HLS Refinement 与 Post-HLS RTL Refinement，并将 Agent-based HLS Design 与 Post-HLS RTL Refinement 组合为 AHRR。
- 在 11 个任务的基准套件上，AHRR 相较 Direct RTL Design 取得 2.6 倍几何平均加速；案例表明 HLS 将设计知识蒸馏为 agent 可利用的抽象，而 RTL refinement 恢复低层优化机会。
- 研究使用 FPGA 进行端到端评估，但所讨论的设计流程权衡基本与目标工艺无关，为结合 multi-agent、tool calling 与 RAG 的 agentic 芯片设计工作流提供了 promising 方向。

### [SpecOpt: 面向结合特异性的智能体分子优化中的接触差异推理](https://arxiv.org/abs/2609.21165)
- SpecOpt 提出一个分子设计任务：对已有小分子药物做受约束的结构修改，在保持结构同一性与类药性质的前提下，提升其对目标靶点相对已知脱靶靶点的结合偏好，而传统基于结构的分子设计多聚焦于从头生成选择性化合物。
- 作者构建了基于 ChEMBL 的基准（915 个化合物），并提出一个 agentic 框架：将化合物分别对接至目标靶点与脱靶靶点，通过残基感知的原子-蛋白接触比较对接构象，再把差异相互作用信号交给大语言模型（LLM）以提出靶向结构修改，候选仅在满足分子相似性、ADMET 与目标-脱靶对接选择性标准时被保留。
- 结果显示该智能体使 84.8% 的化合物目标-脱靶结合差距得到改善，平均差距从 -0.72 提升至 +0.47 kcal/mol，且与起始化合物的平均 Tanimoto 相似度为 0.72；消融实验表明残基特异性接触信息是关键优化信号，用二元接触指示替代残基身份后全部 29 个消融化合物均无改进。

### [AI-GRACE：Agentic AI 用例操作化框架：从组织目标与义务到部署能力与架构](https://arxiv.org/abs/2609.21192)
- AI-GRACE 连接组织治理与技术实现，通过七个风险领域评估并推导部署前的 assurance 要求、运行时控制及证据，指导能力资格认定、差距评估与逻辑架构设计。
- 框架提出 Agent Operating Envelope 明确允许动作与升级条件，并用 Risk-Aligned Independence Levels (RAIL) 总结授权自主程度；以虚构零售银行案例演示方法。
- 该方法基于设计科学与情境方法工程，为组织提供可追溯依据以决定必须实现、已支持及未解决的事项，但尚需实证评估 deployment 决策、效率与复用方面的改进。

### [When LLM Agents Fail to Read the Room: ReAdapt for Relational Social Reasoning](https://arxiv.org/abs/2609.25284)
- 论文提出关系推理基准，包含 500 个合成社交世界与 1,000 个查询，覆盖 reaction selection 与 warm introduction 任务；其中约 53% 的查询里表面最显眼的候选人与基于关系的 oracle 不一致，形成 overturn 子集，暴露标准 LLM agent loop 在关系线索与内容线索冲突时偏向表面选择的失败模式。
- 作者提出 ReAdapt（Relationship-Adaptive Agent with Policy-driven sTate），在 ReAct 循环上引入显式结构化社会状态 z = (G, B, R, N, D)，分别刻画 goal、belief、relationship、norm 与 disclosure，并在每次 tool observation 后执行带类型的 Adapt 步骤更新状态并发出 continue、switch、abandon 或 clarify 等 policy operation。
- 在 Gemini-3-Flash 与每任务 n = 150 的分层子集上，ReAdapt 将 warm-introduction 准确率从 37% 提升到 51%（+14 点），reaction-selection 准确率从 69% 提升到 77%（+8 点），oracle regret 分别从 0.260 降至 0.152、从 0.095 降至 0.053，表明在模型、工具与环境固定时，显式关系状态自适应能帮助 LLM agents 把检索到的社交证据转化为修正后的决策。

### [预测智能体何时该推理？可靠性路由的行为压力测试](https://arxiv.org/abs/2609.28475)
- 论文提出 ReliabilityRoute 结构性干预方法，基于历史覆盖率、市场先验可得性、来源先验锐度、证据强度、证据分歧和预测周期等可靠性特征，来引导预测智能体的行为，而非默认依赖语言模型推理。
- 核心发现是机制选择取决于来源：在某些数据生成过程中结构化类比占优，而在其他情境下市场/群体式与保守基线更可靠，表明更多推理并非总是更好，预测智能体应先估计哪一证据来源值得控制。
- 在 ForecastBench 风格二元预测任务上，固定 2024 年拟合规则无需硬编码来源名称即可接近人工分类法，而基于已解决历史版本的 walk-forward 自适应阈值规则在后续 16 个 LLM 版本上取得最佳平均 Brier 分数，但增益有限且历史/搜索基线仍极具竞争力。

### [TW3Cast: 一个冻结路由器，基于轻度微调基础模型的时间序列预测系统，在 GIFT-Eval 上完全通过训练集选择](https://arxiv.org/abs/2609.28506)
- TW3Cast 不使用 agent 或 language model，其选择表在训练集上计算一次后冻结，专家是公开基础模型（Chronos-2、TiRex、Toto）的轻度微调版本，通过 LoRA 或全量微调实现。
- 对于 97 个数据集、频率和预测范围的配置，该表提供四种模式之一：专家模型、包含专家的分位数混合、基础模型混合，或在训练集回测上进行的选拔锦标赛。
- 通过双重准确性和校准标准、针对训练中见过序列的候选模型的不对称边际以及保守的逐窗口门控来保护选择，最终完整路由器达到平均 MASE 排名 19.4，优于最佳基础模型（33.8）和锦标赛（38.0）。

### [PAWS: 政策驱动的 Agentic World Simulation 数据集](https://arxiv.org/abs/2609.28547)
- PAWS 覆盖 36 个经核实的美国金融与经济政策事件，包含 12,727 条政策相关新闻记录和 65,291 条有来源支撑的利益相关者行动，每条行动通过多层事件框架刻画交互模式、金融行动族与子类型、语义属性及外部分类映射。
- 实体被归一到标准化组织，行动与每日市场收益上下文对齐以支持 policy-agent 模拟回放；在 2,522 个分层行动样本上，独立 AI 与人类评审者对交互模式的初始一致率达 89.4%，分歧随后经仲裁解决。
- 2008 年卖空禁令与 2001 年十进制化案例研究在密集与稀疏新闻设定下复原了政策时间线与市场模式，回放研究则揭示高准确率可能掩盖对稀有利益相关者行动的漏检，凸显行动时序与校准是 RAG、tool calling 与 multi-agent 金融模拟的核心挑战。

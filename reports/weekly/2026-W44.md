### [Phronix：面向 Agent 的能力中心学习范式](https://arxiv.org/abs/2610.31789)
- Phronix 通过 predictor-validator-corrector 循环，让 agentic harness 从自身执行中获取、验证并精炼可复用能力，借助 MCP tools、关联 skills 与 capability store 解决重复劳动，而非反复重新发现方案。
- 学到的能力可在首次尝试中解决重复任务，跨模型成功率达 93-95%，每个任务自动产生 7.6-30.8 个持久能力，且所需能力存在后新能力创建降至两个以下。
- warm-start 每任务仅消耗 0.38-0.40 百万 tokens，比单次基线尝试少三到四倍；在 1000 Genome Pegasus workflow 上通过全部 11 项正确性检查，并将两个低成本模型在 SWE-bench 上的解决率从 29% 和 27% 提升至 91% 和 87%。

### [Don't Forget What You Just Learned: Self-Directed Repair Turns Agent Mistakes Into Lasting Lessons](https://arxiv.org/abs/2610.31846)
- 提出 Self-Direction 机制：agent 任务失败后反思自身轨迹并提炼教训，即时蒸馏为轻量低秩 adapter，原始权重保持冻结，每个 adapter 仅约 0.02% 基础模型参数量，避免全参数微调的高成本与能力干扰。
- 将 adapter 存入持久的经验教训库并按需路由复用，在 GAIA、Claw-Eval、Terminal-Bench 2.1 上借助 Qwen 系列开放权重模型的 agent 将整体成功率提升 8.9 至 17.0 个百分点，并显著减少未来同类任务的重复错误，使纠错可靠性接近翻倍。
- 少量 adapter 可迁移泛化到数十个新任务而无需额外训练，未来可与 RAG、tool calling、multi-agent 等方向结合，把日常错误转化为持久经验。

### [TACS-RF：工具驱动的射频与毫米波模块智能体电路综合框架](https://arxiv.org/abs/2610.31882)
- LLM 编码智能体（Claude Opus 4.8）通过 tool calling 直接驱动 Cadence Virtuoso/Spectre、Calibre、Cadence EMX、Ansys HFSS 等 EDA 工具，实现射频与毫米波模块的端到端智能体电路综合
- 在 90 nm SiGe BiCMOS 工艺上，半自主完成 240–251 GHz 亚太赫兹发射机设计，包含 VCO、功率驱动级、倍频器、差分蝶形天线及级间匹配网络，输出 +5.1 至 +6.3 dBm，1 MHz 偏移相位噪声 -80 至 -88 dBc/Hz，直流功耗 361 mW
- 阐述智能体驱动设计流程与人机分工，向射频/毫米波硬件的“text-to-ASIC”未来迈进；该工作为后续引入 RAG 与 multi-agent 协作提供了可扩展的 MCP 工具调用范式

### [Permission to Retry：AI Agent 工作流中的授权与恢复研究](https://arxiv.org/abs/2610.31916)
- 该论文将 tool-using AI agent 的恢复决策从语言模型行为中隔离，把 checkpoint 状态、dispatch 权限、外部效果证据与 reconcile 权限作为四项独立义务，在 LangGraph 与 Temporal 上执行 336 条历史做有限一致性检验。

- 对 Arya.ai 企业 AI 平台 InfinityOS 的 16 例组件研究覆盖导出的 authority、worker、recovery 与 settlement 代码，将当前授权、provider contract 与保留观测在恢复中的角色分离，并分别报告安全、完成与未解决义务。

### [检索不足：Agent 记忆中的过时事实](https://arxiv.org/abs/2610.36308)
- 在 MemoryAgentBench 单跳 FactConsolidation 任务中，Qwen2.5-7B-Instruct 在 6K 历史下，将 BM25 检索证据预算从 64 token 增至 512 token，准确率反而从 45% 降至 32%，尽管 gold-assisted 事后审计发现每次检索集都包含最新陈述。
- 在冻结 prompt 且证据均为四句的条件下，用过时竞争陈述替换一条无关语句，会使 Qwen2.5 准确率从 100% 降至 44.6%，Qwen3-14B 从 100% 降至 87.8%，所有 50 个有害配对翻转均被归类为 stale。
- 32K 历史复现同样显示 BM25-64 优于 BM25-512（69% 对 58%），说明仅靠 RAG 检索到正确事实并不够，过时竞争陈述比同尺寸无关证据更具危害性，这对 tool calling 与 multi-agent 记忆设计有直接启示。

- 构建跨学科开放研究问题语料库，收录 12,151 个问题并记录问题陈述、背景与研究进展；同时提供 200 道数学问题的回顾性基准，其中 110 道于 2026 年解决、90 道仍开放，每道题都配有经自动探测与两次独立审核检查的 Lean 4 陈述，HQ-50 子集进一步按质量分筛选。

- 通过将广泛的研究问题语料库与带文档解答、经形式化评分的评估子集相连接，OpenFrontiers 为衡量研究级再发现、研究面向当前开放科学问题的进展提供了基础，并可用于评估 tool calling、RAG、MCP 乃至 multi-agent 等研究型 LLM 系统。

- 该框架构建了覆盖 14 个应用领域、53 个类别的 244 个网站 artifact，支持 12,984 个已执行且被接受的任务；与人工辅助的 WebHarbor 相比，WebAnything 在三项保真度指标上总分更高，盲审结果为 12 胜、2 平、0 负。
- 在固定 harness 下，用 5,856 条交互轨迹微调 Qwen3.5-9B，使 REAL 成功率提升 9.9 个百分点，Odysseys-Easy Rubric Avg 与 Task Avg 分别提升 6.25 和 6.32 个百分点，WebArena-Verified Overall 成功率提升 13.33 个百分点。

### [本体能捕捉什么？ curated、LLM 生成与数据派生本体作为知识图谱上 LLM Agent 检查器的研究](https://arxiv.org/abs/2610.37809)

## Research and engineering

### [Occamy-1.0：面向 Co-work 的开放 Pareto-frontier 35B 智能模型](https://arxiv.org/abs/2609.11977)
- Occamy-1.0 基于后训练 Qwen3.6-35B-A3B checkpoint 进一步训练，通过构建执行接地数据与环境、采集跨多种 harness 的可回放长时程轨迹，并采用分阶段后训练来发展并巩固互补的执行能力，从而获得高性价比的 co-work 模型。
- 在广泛的 co-work 基准上，Occamy-1.0 始终位列同规模模型最强梯队，并在多项任务上与显著更大的 frontier 系统保持竞争力；在其评估与定价协议下，四项代表性基准的综合表现使其位于成本--性能 Pareto frontier 的低成本拐点。
- 在 tool calling、coding 与 instruction following 上的支持性评估表明该专精化保留了广泛的 agentic 能力，同时模型权重与部分训练数据已开放，以支持实用 co-work agents 与 agentic post-training 的研究。

### [Harness 还是 Model？在受污染控制的私有测试套件中分离 Agentic Coding 的 Harness 效应](https://arxiv.org/abs/2609.11987)
- 在 256 个私有、受污染控制的仓库与截止后竞赛任务上，对同一模型进行配对对比：claude-opus-4-8 在 claude-agent-sdk 与 deepagents 下、gpt-5.5 在 openai-codex SDK 与 deepagents 下，另设 gemini-3.5-flash 和 deepseek-v3.2 侧格；800 次计划运行中 792 次由隔离 oracle 评分，两个对比均未显示任一 harness 的平均优势（Opus 4.8 为 -1.25 个百分点，GPT-5.5 为 +1.25 个百分点，置信区间均含零）。
- Opus 平均值掩盖了相反分层：原生 harness 在 61 个仓库任务上落后 9.0 个百分点，但在 19 个竞赛任务上领先 23.7 个百分点（标签置换 p = 0.003）；该分层是观察数据后选择的，需要设计性复现。正确性与完成度也分离：81 次在挂钟上限取消的运行中，有 22 次已产生通过补丁。
- 按冻结标价从原始每轮用量重新计价，在 Opus 4.8 上中性 harness 每解决任务成本为原生 harness 的 1.3 至 1.6 倍，在 GPT-5.5 上为 1.2 倍；这些是基于观察用量的估计，且 Anthropic 账户有 58 次运行无用量记录，将这笔支出分配给任一格会使 Opus 比率在 0.7 至 2.3 之间移动，因此计费排序仍未解决。本修订更正了 2026 年 8 月手稿中因自身遥测的用量语义缺陷导致的成本数字（第 5.1 节），并发布 orchestrator、评分 oracle、再分析代码和派生聚合数据，任务保持私有。

### [WinSyn: 面向真实企业问答评估的自动化流水线](https://arxiv.org/abs/2609.12171)
- WinSyn 是一个自动化流水线，用于生成反映真实职场场景的合成邮件数据集，并附带基于数据的长短型问题和标准答案，旨在解决现有基准缺乏真实企业复杂度的问题。
- 该方法模拟跨越数月、涉及多达 25 名多角色员工交互的长期企业项目，数据强调歧义性、分布式信息和自然发生的查询，以支持 RAG、Deep Research 和 tool calling 等评估。
- 在多个标准 agentic 基线和最新前沿模型上的评估显示，所有数据集的平均聚合得分均低于 80%，表明企业级 multi-agent 和 DR 系统部署仍有显著改进空间。

### [GTA：基于图论智能体与基准的 LLM 算法图推理](https://arxiv.org/abs/2609.12265)
- 提出 GT Bench 基准，覆盖 24 个经典图问题、44 种任务结构设置，包含自然语言、结构化语言、邻接表和邻接矩阵四种表示下的超过 10 万个示例。
- 评估八个 LLM 发现准确率强烈依赖输入表示，最佳表示随图密度、规模、拓扑和模型变化，且在最强推理模型中这种敏感性依然存在（有所减弱）。
- 提出 GTA，结合偏好训练的表示选择器与围绕冻结执行器 LLM 的 plan-and-decompose 脚手架，在 easy/hard 划分上分别将 Phi-4 从 53.5% 提升至 69.1%、从 33.0% 提升至 41.5%，并无需重训练即可迁移到 GraCoRe 和 NLGraph。

## Research and engineering

### [EvolveTrade：面向自进化 LLM 交易代理的经验驱动策略精炼](https://arxiv.org/abs/2609.17632)
- EvolveTrade 将工具调用交易代理的系统提示词视为文本参数化策略，在保持骨干 LLM 固定的前提下，由 Policy Agent 利用累积决策轨迹与实际组合反馈定期修订该策略，实现自进化式 policy refinement。
- 在多种市场状态和两个 LLM 骨干上的实验表明，EvolveTrade 在多数评估设置中提升了 Sharpe Ratio 和 Cumulative Return，优于固定策略的 LLM 基线，并增强了 code-mediated analysis 与 regime-relevant computations。
- 案例级 policy-to-return 归因揭示了策略诱导的配置变化如何贡献实际收益差异，表明适应可复用的 tool calling 程序是构建更稳健 LLM 交易代理的关键方向，也为多代理与 RAG 增强的交易系统提供启示。

### [GraphEcho：LLM 图智能体中的结构冗余与证据溯源](https://arxiv.org/abs/2609.17695)
- GraphEcho 基准测试 LLM 智能体是否将图中重复路径误认为额外独立证据。
- 冗余支持路径增加了所有冻结智能体的重复游走比例，而溯源感知后训练（PAPT）虽减少重复并提升合成准确率，却覆盖更少不同来源。
- 在科学声明上，PAPT 持续减少重复但准确率下降，揭示高效探索与有效利用证据之间的差距。

### [NeMo Data Designer：面向多模态合成数据生成的可扩展框架](https://arxiv.org/abs/2609.17699)
- NDD 是开源通用框架，采用声明式配置定义数据集各列，列类型覆盖文本、代码、结构化输出、图像、embeddings 及用于调控数据集多样性的统计采样器，并可通过插件系统扩展。
- 框架将 SDG 视为迭代过程，内置 preview-and-revision 循环，支持小批量生成与检查、优化 specification 后全量重跑；配置本身是可检查 artifact，便于 workflow 共享与复现。
- 运行时 NDD 解析依赖、调度对用户模型端点的调用并重试失败请求；案例研究涵盖结构化、agentic、多模态与领域专用任务，覆盖 MCP、RAG、tool calling、multi-agent 等场景，并已用于 Nemotron 模型开发与生产级企业部署。

### [BioPhys-Bridge：物理基础生物学跨学科科学推理基准](https://arxiv.org/abs/2609.19180)
- BioPhys-Bridge 以证据块、稳定 evidence IDs、定量数值与单位、方程、假设、机制和后续决策为 grounding 目标，支持 QA 与 RAG，首版含 500 个案例、1,517 个 agent-facing 任务，覆盖六个生物域和九个物理模型族。
- 数据集设置 schema、证据完整性、定量 grounding、来源许可、去重、单位归一化等严格质量门，并由领域专家复审核注 81 个案例，用于评估 attribution、faithfulness、幻觉削减和生物实验设计等复杂多步科学推理。
- 初步评测显示 DeepSeek-V4-Flash 的 evidence-ID F1 最高（0.360），其后为 Qwen3.7-Max（0.316）和 GPT-4o-mini（0.294）；未来将扩展规模与复杂度并开展全面评测，代码与数据已在 GitHub 和 Hugging Face 发布。

### [我们期望 LLM 做什么？映射 LLM Benchmark 的设计](https://arxiv.org/abs/2609.19182)
- 该研究系统梳理了 2022 年 1 月至 2026 年 8 月 arXiv 上 14,767 篇引入或更新评估资源的论文，揭示 LLM benchmark 在目标系统与领域、评估材料与条件、评分机制上的设计变迁。
- benchmark 设计日益强调行动、交互与专业应用，且新旧设计元素常并存；基于 LLM 的评分在 agent 与非 agent 组中均持续增长，而模型生成材料在近期队列中未见可比增长。
- 随着 AI 参与构建测试、执行任务与评判回答，研究提出关键问题：不断扩展的评估是提供了更多独立证据，还是可能复制参与模型的偏好与盲点，这也关系到 RAG、tool calling、multi-agent 与 MCP 等应用场景的评测可信度。

### [立场：是时候用自演化的操作系统层虚拟化基础模型了](https://arxiv.org/abs/2609.19203)
- 当前复合 agentic 系统技术栈高度碎片化：尽管 MCP、A2A 等协议简化了工具与智能体连接，各框架仍内嵌用于状态、记忆、预算与护栏的隐式运行时，导致行为不可移植、治理脆弱，如同操作系统出现之前每个程序都要重新实现基础服务。
- 作者主张引入 Foundation Model Operating System（FMOS）作为系统层，像虚拟机抽象物理硬件一样虚拟化 FM 交互，让应用获得专属、可信且能力近乎无界的基础模型实例幻觉；其内部负责跨记忆层级编排知识、模型选择与资源分配、以及验证与策略执行。
- 类比人脑在快速直觉与缓慢审慎之间切换，FMOS 需要学习何时介入、何时让 inference 直接进行，并基于运行经验持续自适应其策略，这一能力也与 RAG、tool calling、multi-agent 等机制的组织与调度密切相关。

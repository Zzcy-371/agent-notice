## Research and engineering

### [NormGym：通过社交互动评估规范能力](https://arxiv.org/abs/2611.08613)
- NormGym 是一个交互式基准，要求新来者在 multi-agent 社区中完成自身任务的同时，从社交互动中推断隐藏的任意规范，并区分“可能”与“被允许”。
- 当前最强 LLM agent 的任务与合规联合成功率仅为 55.3%；模型能根据自身受到的制裁调整行为，但难以利用其他 agent 的行为及其所受制裁来推断潜在规范。
- 研究发现微调可能不足以提升规范能力，表明当前模型缺乏通过社交互动获取规范知识的稳健且可迁移的能力。

### [Decision Context：为 AI Agents 实现持久行为学习](https://arxiv.org/abs/2611.08644)
- 针对 LLM agents 无法跨会话学习纠正、现有 agent memory 系统只处理事实而非程序性知识的问题，论文提出 Forge Decision Context（forge_dc），从人类纠正与自评的 tool calling 失败中提取行为信号，编译为命令式 RULE 指令，并在适用的决策点注入。
- 在基于真实 agent 执行轨迹构建的 DC-Bench（覆盖 9 个行为维度、71 个场景）上，forge_dc 达到 95% 合规率，而朴素 RAG 仅 55%，且每次查询注入的 token 约少 10 倍。
- 五阶段演进表明，最强的系统把行为记忆表示为显式指令，并在适用的决策点交付；representation、activation 与 placement 是持久行为学习的核心设计选择，也为 MCP、tool calling 与 multi-agent 场景提供参考。

### [调试接口对比：调试器代理与仅 Bash 代理在 SWE-bench 上的 pass$_X$@$k$ 评估](https://arxiv.org/abs/2611.08666)
- 在固定 scaffold 的前提下，对比仅使用交互式 debugger 的 agent 与仅使用 bash 的 agent，覆盖全部 500 个 SWE-bench Verified 实例，并在 GPT-OSS-120B 与 Nemotron-3-Ultra-550B 上各独立运行三次。
- 提出跨 agent 的 pass$_X$@$k$ 指标，用于区分接口专精与重复采样带来的覆盖扩展，并对“至少一个 agent 成功”的概率给出无偏估计。
- 结果显示 bash 与 debugger agent 单次运行解出的子集虽部分不相交，但 pass$_X$@$2$ 表明这主要来自运行间随机方差而非工具互补性；两个 bash rollout 优于一个 bash 加一个 debugger 的组合，强调评估 agent 与 tool calling / multi-agent 多样性时需考虑随机方差。

### [Memory-Aware Multi-Agent Architecture with LLM-based Orchestration for Conversational Recommendation](https://arxiv.org/abs/2611.08718)
- 将长期记忆作为一等组件集成到 multi-agent 架构中，由 LLM 承担 orchestration 层，协调意图细化、查询构建与交互流程，使记忆同时影响路由决策与语义查询构造。
- 在 Amazon Reviews 数据集上的跨会话记忆实验、多轮对话模拟与 supervisor 驱动交互研究表明：启用记忆的交互可弥补至多 63% 与显式查询场景之间的差距，并避免长对话中的语义退化；监督式 orchestration 使用户接受度提升 28.9 个百分点。
- 观察到检索候选与展示推荐之间存在曝光瓶颈：LLM-reranking 虽不提升 Hit@K，但持续改善语义一致性与多样性，为此提出 Semantic Consistency Score（SCS）作为传统排序指标之外的补充评估度量。

### [Debate to Deceive：基于博弈论多智能体辩论的LLM事实核查投毒](https://arxiv.org/abs/2611.08756)
- D2D 将 multi-agent debate 建模为演化博弈，让智能体通过竞争自适应演化 Logos、Pathos、Ethos 等修辞策略，生成语义连贯且能规避早期确认偏差的对抗性段落。
- 为应对 LLM 输出空间过大的问题，D2D 将智能体行为解耦为策略层与生成层，前者在紧凑策略空间中用演化学习动态选择修辞动作，后者由 LLM 基于该策略与辩论上下文生成具体文本。
- 在 FEVER、HealthVer、CLIMATE-FEVER 和 SciFact 四个事实核查基准上，D2D 显著优于现有对抗后缀/模板注入与单智能体自反思方法，并能绕过大多数防御。

### [Aligning, Fast and Slow：面向长时程轨迹与持续部署的控制论监督框架](https://arxiv.org/abs/2611.08781)
- 提出一个控制论监督框架，将控制提议动作的快循环与审查持久变更、并在模型或工具更新后重新评估配置的慢循环耦合，为长时程轨迹与持续部署提供部署级监督。
- 在测量误差与检查间变更均有界且控制器可强制执行决策的条件下，推导出部署级界限与审查资源分配规则；模拟中将固定审查预算分配给两个循环，相比仅审查单次运行，可将相对预期行为的平均最大偏离降低约十二倍。
- 编码压力测试中，组合控制将 0-3 严重度均值从无门控的 0.325 降至 0.117，解决 120 个问题中的 33 个（无门控为 35 个）；交易压力测试中，组合控制将低排放采购的平均短缺从 0.892 降至 0.107，帮助开发者与审计者比较并执行监督设计。

### [思维注入攻击对推理型智能体的评估](https://arxiv.org/abs/2611.08811)
- 研究针对 GLM-5.3、MiniMax-M2.5、Qwen3.8-Flash-Next 等主流开源大模型开展思维注入攻击测试，发现 thinking tags 与 payload 样式的效果均取决于具体目标模型。
- 在容器化 agentic cyber range 中，利用模仿目标模型自身推理轨迹的间接注入提示，对 reverse-shell 外传、仓库后门等操作目标实现最高 50% 的 attack success rate (ASR)；而同样恶意目标以用户口吻的标准 prompt injection 从未成功。
- thinking tags 会抑制智能体披露注入内容，且 tag stripping 作为防御手段不可靠，表明模仿推理模型自身思维风格对该类攻击有效。

### [EarthRecord：基于四十年卫星影像的多模态智能体土地变化分析基准](https://arxiv.org/abs/2611.12934)
- EarthRecord 构建于 56 个站点的原始多传感器记录之上，涵盖四十年 Landsat、MODIS、VIIRS 和 Sentinel-2 数据，云掩膜与跨传感器协调等预处理均交由 agent 自行完成。
- 该基准包含十类分析任务下的 238 个土地变化问题，并以全球产品留出参考、方法间一致性和目视解译进行评分，同时设置“closed book”与传感器数据篡改两组对照，检验答案究竟依赖何物。
- 对十二个 multimodal agents 的评估显示，领先 agent 能端到端完成多数分析，但在需要从影像映射到答案时表现不佳；且当某一卫星数据被改动时，约一半正确答案会随改动而改变，说明其尚未真正落到地表真实变化上。

### [AI Governance Should Prioritize Control and Knowledge Boundaries Over Limiting Intelligence](https://arxiv.org/abs/2611.12941)
- 论文提出“能力回路”（IKC + KC + C）框架，将智能体的现实影响分解为智能中介的发现、程序性 know-how 与直接控制三条路径，并用 fast-takeoff 辩论作为压力测试，论证多数快速灾难性优势依赖快速知识获取或控制获取而非单纯智能。
- 基于 NK 适应度景观的随机模拟与解析界表明，智能驱动的加速受竞争智能水平之比封顶，且“fast-takeoff 困境”意味着大加速倍数只在假设空间嘈杂时出现，而绝对时间尺度仍受能力关键测试所需时间约束。
- 作者主张主导安全杠杆是限制控制与执行知识边界，而非仅限制智能；制度性 chokepoints 在强制授权延迟显著时能不成比例地拖慢超级智能体，纯数字领域会削弱这些瓶颈，因此需要有意“把物理放进回路”的架构；该结论适用于任意能力水平的 agentic systems，并与 MCP、RAG、tool calling、multi-agent 等系统治理相关。

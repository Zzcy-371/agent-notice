### [ScopeBench：智能体在目标压力下能否守住交战边界？](https://arxiv.org/abs/2609.30325)
- ScopeBench 包含 30 个死胡同式智能体安全任务，其目标只能通过违反既定 scope 才能达成；每个任务在共享环境、验证器与目标下分设无 scope（衡量能力）与自然语言 scope（衡量遵循）两种条件。
- 评估采用双通道评分：无 scope 轨迹由确定性验证器评分；有 scope 轨迹先经同一确定性验证器检查 flag（通过即证明发生了越界动作，给出违规率高精度下界），未通过则由 agentic judge 估计是否存在 out-of-scope 调用。
- 在 8 个模型的同一 harness 中，原始能力跨度为 12.2%–81.1%，scope adherence 跨度为 34.4%–86.7%；judge 找出了机械验证遗漏的 331 次违规，且 Opus-4-8 的原始能力比 sonnet-4-6 高 10 个百分点，同时 scope adherence 高出 35.6 个百分点。

### [多智能体代码评判何时真正有据？两项无标签测量，以及一个拒绝猜测的评判器](https://arxiv.org/abs/2609.30328)
- 论文指出多智能体验证（multi-agent）方法依赖证据的两个条件：证据必须独立于被审查答案，且必须在两个候选方案之间存在差异；后者在检索文档场景自动成立，但在代码评判中失效。
- 在 MARCH 框架上跨两个代码评判基准进行 80 项条件×单元测量，发现其在 78% 至 95% 的比较中判定两个解决方案同样好，准确率仅 4.4%，而直接提问同一模型可达 43.7%，更简单的问题或更大的评判器均无法改变。
- 基于流程自身日志的两项无标签测量可解释该现象，并用于门控：评判器拒绝无法判断的比较，在仍回答一半比较的情况下将准确率从 20.7% 提升至 36.9%，贡献在于提供一种无标签判断评判器是否有据的方法。

### [SMARtCARE：面向有限自主临床决策支持的隐私保护智能体 AI 系统](https://arxiv.org/abs/2609.31763)
- SMARtCARE 采用四状态临床决策支持架构：Stable、Meta-cognitive、Assisted 和 Regulated (Revoked)，通过有损六通道指纹匹配患者历史轨迹，在上下文缺失时触发 Meta-cognitive 升级，仅在 Assisted 状态下由临床医生操作进行完整检索，实现隐私保护的 bounded-autonomy。
- 系统集成 patient-identity guard 确保数据加载、日志记录和审计层的正确归因，并在 MIMIC-III 和 MIMIC-IV 上验证：MIMIC-III 中 14 名两次入院患者识别出 1 例先前模式复发，MIMIC-IV 中 9 名两次入院患者无指纹匹配，所有决策均可追溯且归因正确。
- 评估结合合成蒙特卡洛研究验证状态转换逻辑与估计器稳定性，但非临床性能；结果表明 SMARtCARE 是一种可追溯、隐私感知的中间上下文风险提示机制，而非临床疗效声明。

### [CP-Agent：用于晶体塑性仿真工作流的harness工程智能体](https://arxiv.org/abs/2609.31790)
- CP-Agent 是基于 LLM 的 harness-engineered 智能体，采用 ReAct 范式，自主完成晶体塑性（CP）建模工作流，从自然语言任务出发，将数值搜索委托给成熟优化器，并通过类型化 tool 定义、dispatcher 和安全有界迭代循环编码领域知识。
- 在四个案例研究中，CP-Agent 成功校准增材制造 316L 不锈钢的四个滑移参数、复现铜基准的应力-应变与织构演化、恢复铜的初始晶体织构（正确识别为弥散织构），以及再现 Mg-Zn-Ca 合金多道次轧制织构演化（链式五道次变形并恢复实验观察到的弱化分裂基面织构）。
- 该工作将 harness engineering 确立为自动化 CP 建模工作流的系统方法，通过可见推理轨迹保持物理可解释性与可审计性；其架构整合了 MCP、RAG、tool calling、multi-agent 等术语所代表的模块化与协作机制，为系统参数研究提供高效自动化路径。

### [COUNTERMEM：面向语言智能体的世界模型验证反事实记忆](https://arxiv.org/abs/2609.31874)
- COUNTERMEM 是一个强化学习框架，在动作失败后借助可执行世界模型（如测试、证明检查器和求解器）从原始状态的副本或重置中评估局部替代方案，构建经过验证的反事实记忆，存储原始与修正动作、已检查结果及复用条件。
- 学习到的记忆使用策略可选择检索到的记录或跳过记忆，以平衡任务成功与交互成本，同时基础 LLM 保持固定；记忆与策略在留出评估期间均被冻结，并可与 ReAct、Reflexion 等 multi-agent/tool calling 流程结合。
- 在六个领域 12 个基准设置上，使用 gpt-oss-120b 时 COUNTERMEM 平均提升 12.6 个百分点，任务运行 token 减少 7.7-42.0%；分析表明移除验证或持久化存储会削弱增益，而将验证后的修正应用于不适宜决策可能产生反效果。

- AREX-2 将自我改进定义为测试时迭代优化解决方案的能力，其核心是 reflection（反思）与 long-horizon execution（长时程执行），二者被认为与领域无关，可在适合监督的场景中习得。
- 该方法从机器学习与算法编程任务中合成 long-horizon 改进轨迹，利用可验证反馈与持续迭代奖励训练基于 Qwen3.8-27B 的 agent，在 MLE-bench Lite 取得 81.8、Frontier-CS 取得 70.7。

### [MoFlow: 多目标 Agentic Workflow 生成](https://arxiv.org/abs/2609.38294)
- MoFlow 将工作流生成建模为多目标马尔可夫决策过程，并用 Convex-Hull Monte Carlo Tree Search 与乐观集值备份求解，每个节点存储一组可达权衡而非单一加权分数。
- 单次搜索即可近似覆盖 Pareto 前沿，MoFlow 能通过查找为任意偏好返回工作流，无需重新训练，而现有方法通常只优化准确率或加权和，偏好变化时须从头重训。
- 在数学、代码和问答六个基准上，即使基线针对每个测试偏好重新运行（MoFlow 从未见过这些偏好），MoFlow 仍取得最高平均 hypervolume。

### [AI Agents are Vulnerable to Radicalization](https://arxiv.org/abs/2609.38296)
- 研究发现，LLM agent 之间可以相互影响：扮演人类人设的 target LLM 会被 influencer LLM 推向更极端的信念，说明 AI agents 在 multi-agent 交互中存在被激进化风险。
- 激进化有两条路径：resonance（强化 target 已有信念）和 persuasion（让 target 接受原本不重视的信念），两者都能使 target 更极端，但 resonance 的效果始终强于 persuasion。
- 不同影响策略（如 sycophancy、unverified claims）会导致不同程度的激进化，且在各项指标上并不一致；resonance 还会传播到相关信念，凸显了个性化 AI agents 与 multi-agent AI ecosystems 的脆弱性。

### [重尾记忆痕迹：长时程语言代理的记忆审计与核心-尾部世界模型](https://arxiv.org/abs/2610.00010)
- 论文提出对长时程语言代理进行保守的尾部审计，发现外部记忆使用呈现重尾分布：在有限上下文和重复检索下，记忆集中在小核心，而罕见状态留在长尾中导致预测误差累积；随机行走代理产生对数正态兼容的检索痕迹，语义 LLM 策略则产生最强的截断幂律兼容核心-尾部痕迹。
- 基于审计结果，作者提出 Core-Tail World Model (CTWM)，一种基于排名的记忆控制器，通过单一指数 τ 分配提示预算并保留摘要化的尾部；在 Synthetic Graph World 上，相比图记忆基线，CTWM 保持完整状态和转移覆盖，减少 5.9% 提示 token，并将下半尾部预测误差降低 13.6%。
- 在 ALFWorld 和 LongMemEval 上的配对比较显示一致的 token 节省，LongMemEval 上 token 减少 24.48% 且总体准确率持平，表明重尾记忆痕迹不仅是有限检索的诊断指标，也是实现 token 高效代理世界模型的实用控制信号，对 MCP、RAG、tool calling 和 multi-agent 等场景具有启示。

### [因果世界模型何时助力模块化 LLM 智能体](https://arxiv.org/abs/2610.00012)
- 论文提出 FedCausalCompose 因果世界模型框架，通过局部动作提供跨模块接口的干预-响应证据，指出在未阻断后门路径下观测世界模型存在不可约的干预误差。
- 实验表明因果接口在结构化 tool 环境中收益最大，因为 API 签名暴露了前置条件与下游影响；而在对话和叙事环境中，除非用简短注意力锚点使因果信息与决策相关，否则智能体常忽略原始边列表。
- 结论给出因果世界模型助力 LLM 智能体的具体条件：当跨模块接口既可统计识别、又以 action time 可用的形式呈现时，因果结构才真正有益，对 MCP、RAG、tool calling、multi-agent 等模块化系统具有指导意义。

### [From Proposal to Verified Effect: Praxa, an Evidence-Bound Harness for Governed AI Agent Execution](https://arxiv.org/abs/2610.00015)
- Praxa 是一个 evidence-bound agent harness，通过确定性准入、brokered execution、外部 read-back、reconciliation 与 reviewed promotion，将 proposal、authority、dispatch、verified external effect 和 serving promotion 显式区分并可测试。
- 四条证据通道结果各异：仓库本地审计通过 1,027/1,027 单元测试与 89/89 Workerd 测试但缺少独立复现；Terminal-Bench Core 0.1.1 pilot 中 baseline 与 reliability layer 各通过 17/36 严格试验且后者 token 消耗更高，不支持优越性；coordination-proxy 开发对比中 candidate 与 baseline 均 180/180 且 candidate 少用 37.11% tokens，但未证明质量、延迟或生产行为改进。
- 部署配置证据显示 bounded reflection、recall accounting、memory compilation 与 tool-health 路径，但无生产 outcome lift；当前证据无法确立对抗安全、生产安全、通用 specialist 优越性、自主递归优化或用户收益。

## Research and engineering

### [Oversight Has Capacity: 让 Agent Guards 适配主观且会疲劳的人类监督者](https://arxiv.org/abs/2606.08919)
- 论文探讨 agent 监督的人因瓶颈：人类监督者的注意力有限且会疲劳，因此 Agent Guards 的校准应纳入主观、随时间衰减的监督容量，而非假设恒定满负荷审核。
- 对 multi-agent 与 tool calling 系统而言，这意味着在 MCP、RAG 等工具链中需动态调节拦截、升级与自动执行阈值，把有限的人类审核预算优先分配给高风险或高不确定性的动作。
- 核心启示是监督是一种可耗尽的资源，guard 策略应显式建模人类疲劳与主观判断差异，从而在安全性与可运维性之间取得更实际的平衡。
